# Z1 폭 / 지지 위치 변경의 분리 비교

이 계산은 실제로 실행한 수치 민감도 검토다. 제작·통전·안전 인증 또는 전체 기계의 열성능 qualification이 아니다. 기존 rc1 자료와 이 수정본을 혼용하지 않는다.

## 실행과 입력

저장소 루트에서 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 analysis/final_validation/hot_zone_revision_review.py`를 실행한다. NumPy가 필요하다. 결과는 `analysis/final_validation/results/v0.8/hot_zone_revision_review.json`이다.

`reference_geometry.json`은 공개 기준 e323c54e의 실제 Git 객체에서 추출한 두 파라미터 파일, 원본 SHA-256 및 Git blob ID를 보존한다. 기존 Z1은 45..90 mm이며, 미추적 초안의 40..85 mm 비교 기준은 잘못된 것이었다. 현재 Z1은 45..85 mm다.

| 경우 | Z1 구간, mm | 배럴 후단 기준 지지 중심, mm |
|---|---|---|
| reference | 45..90 | 16, 106 |
| width_only | 45..85 | 16, 106 |
| support_only | 45..90 | 16, 110 |
| combined | 45..85 | 16, 110 |

각 경우에서 접촉 열전달 계수 200/1000 W/(m2 K), 외부 대류 8/15 W/(m2 K), 지지 방열 0.05/0.2 W/K의 8조합을 계산한다. 총 32조건이며 열전도율/비열을 달리한 추가 2조건도 분리 기록한다. 이 값은 측정된 상·하한이 아니다.

## 방정식과 검증

축방향 유한체적과 히터 3개/다이 lump를 사용한다. `C*dT/dt = Q - K*T - G*(T-Ta) - epsilon*sigma*A*(T_K^4-Ta_K^4)`의 내부 연결은 대칭이고 열의 생성·소멸을 만들지 않는다. 전도·대류는 후진 Euler, 복사는 이전 시점 값으로 계산하므로 시간 간격 수렴을 따로 검사한다.

히터 접촉 면적은 실제 축방향 겹침 길이로 분배한다. 히터 열용량도 45 mm의 기준 25 J/K에서 폭에 비례하도록 가정한다. 센서는 셀 중심값을 선형 보간하며 지지 방열은 8 mm 폭의 footprint에 분배한다. 지지 위치를 가장 가까운 셀 하나로 반올림하지 않는다.

시간/공간 세분화 오차의 기존 기준 1 C를 유지했다. 0.5 s, 2.5 mm부터 시작하여 실패한 조건의 격자/시간을 더 줄인다. 최종 공간 격자에서도 시간을 다시 줄여 검사한다. 배럴/다이/히터 최대온도뿐 아니라 종료시 센서 온도도 비교한다.

## 이번 계산 결과와 판단

수치 검증은 통과했다. 시간 세분화 최대차 0.9532 C, 공간 세분화 최대차 0.6979 C, 누적 에너지 잔차 최대 3.92e-7 J다. 최종 시간 간격은 조건별로 다르며 가장 작은 것은 0.03125 s다. 해시가 현재 소스와 일치할 때만 이 결과를 사용한다.

Z1의 명목 접촉 면적은 41.1257 cm2, 100 W 기준 발열밀도는 2.4316 W/cm2다. 같은 4 mm closure gap 가정에서 45 mm 대비 12.5% 증가한다. 이것은 발열밀도의 비율이지 온도 증가율이 아니다.

수정안의 8조건에서 배럴 최대온도는 277.01..292.40 C, Z1 lump 최대온도는 255.83..329.64 C였다. 다른 존까지 포함한 히터 최대치는 346.54 C다. 동일 조건의 기존안 대비 Z1 최대온도 증가는 6.56..14.85 C였다. 1800초 안에 네 센서가 모두 목표의 -5 C 이상에 도달한 것은 3/8조건뿐이다.

따라서 `DIGITAL_DELTA_SCREEN_COMPLETE`를 가열계 적합 판정으로 사용하지 않는다. 공급자 허용 외피온도·실제 접촉·가드 내 방사/대류·실제 PID/센서 응답이 불명확하다. 300 C는 비교 기준일 뿐 공급자 승인 정격이 아니다. 불리한 가정에서 외피온도 초과 또는 목표 미도달이 나타났다는 사실을 P9 계획과 공급자 검토에 전달한다.

구조 비교는 실제 지지 위치의 이상적인 중공 Euler-Bernoulli beam이다. 자중+팁25 N 조건의 최대변위는 기존 0.0064913 mm, 수정 0.0061770 mm였고, 배럴 질량만의 1차 굽힘 모드는 658.61에서680.16 Hz로 변했다. 전체 기계 고유진동수나 모터 공진 회피 판정이 아니다.

수정안에서 후방 반력 약 -50.01 N가 요구된다. 실제 C형 locator/retainer가 이를 받을 수 있는 방사방향 접촉과 틈새를 별도로 검증해야 한다. 선형 beam에서 지지를 양방향으로 고정했다고 실제 지지 용량이 증명되는 것은 아니다.

## 한계와 출처

실제 screw/polymer, 급송부 열유입, 가드 내부 방사 교환, 3D 국부 온도구배, 접촉 비선형, 변형·피로·마모는 이 모델에 포함하지 않았다. PI 테이프의 단열 효과는 가정하지 않았다. +/-1 C relay는 수치 비교용이며 배포 PID나 안전 차단 동작이 아니다.

- Ovako42CrMo4 전형 물성: https://steelnavigator.ovako.com/steel-grades/42crmo4/ . 밀도7800, 저온 비열460..480, 상온 열전도40..45 등의 참고값은 납품 SCM440 고온 인증값이 아니다.
- Tempco mica band의 클램핑/접촉 설계: https://www.tempco.com/Duraband-Heaters.htm . 이것은 이 주문 히터의 승인도면이나 정격 확인서가 아니다.

`test_z1_thermal_model.py` 9개와 `test_hot_zone_revision_review.py` 4개 시험으로 무전력 평형, 단열 에너지 수지, 접촉 면적/열용량 비례, 지지 방열 보존, 잘못된 입력 거부 및 beam 이론해를 확인한다. 실물 상태는 NOT_RUN, machine_release는 HOLD다.
