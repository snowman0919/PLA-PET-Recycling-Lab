# v0.7 탐색 작업 보존 색인

- 조사 시점: 2026-09-03
- 기준 작업트리: `7de9bf2a6e4c91c7fa6b58da9c729e63dc52e3a0`
- 수치 증거 상태: **재사용 금지**

현재 저장소, 로컬 branch, worktree 및 실행 프로세스를 조사했으나 `v0.7`로 식별되는
스크립트·로그·스크린샷·결과 JSON은 발견되지 않았다. 실행 중인 Fusion, Inventor,
CalculiX, Gmsh, FreeCAD 또는 OpenModelica 작업도 없었다. 일반 MCP 프로세스는 이
프로젝트 작업으로 입증되지 않아 종료하지 않았다.

첨부된 v0.8 목표 문서에만 나타나는 아래 값은 원시 결과와 모델 입력이 없으므로
`DIAGNOSTIC_ONLY`로 분류한다.

|항목|전달된 값|분류|최종 설계 사용|
|---|---:|---|---|
|LC04 최대 변위|약 0.0147 mm|`DIAGNOSTIC_ONLY`|금지, 깨끗한 재실행 필요|
|LC07 안전율|약 1.42|`DIAGNOSTIC_ONLY`|금지, mount BC 재정의 필요|
|LC08 안전율|약 1.11|`DIAGNOSTIC_ONLY`|금지, mount BC 재정의 필요|

기존 v0.6.2.1의 추적된 solver 결과는 v0.7 결과가 아니라
`VALID_REFERENCE`인 역사적 기준이다. v0.8 release evidence는 동결된 새 pipeline을
깨끗한 결과 디렉터리에서 실행해 별도로 생성한다.
