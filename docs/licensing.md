# 라이선스 적용 범위

## MIT

루트 `LICENSE`의 MIT License는 다음에 적용한다.

- `firmware/`
- `software/`
- `cad/generation/`과 기타 생성·검증 스크립트
- 실행 가능한 계산·시뮬레이션 코드

## CERN-OHL-P-2.0

루트 `LICENSE-HARDWARE`의 CERN Open Hardware Licence Version 2 - Permissive는 다음 hardware source에 적용한다.

- `cad/freecad/`, `cad/parameters/`
- `electronics/`
- `exports/drawings/`와 제작용 도면
- 장치의 기계·전기 설계 정의

각 파생 산출물은 source의 part number와 revision을 보존한다. 외부 부품의 datasheet, vendor model, third-party library는 원 저작자의 라이선스를 유지하며 본 프로젝트 라이선스로 재허가하지 않는다.

공식 원문 확인 출처: CERN Open Hardware Repository의 CERN-OHL-P-2.0 배포본, 2026-08-28 확인.
