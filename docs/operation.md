# 운전 원칙 — pre-release

현재 장치는 설계 단계라 실제 운전 절차로 사용할 수 없다. 최종 절차에는 startup self-test, batch 선택, dry recipe, purge, extrusion, first-strand manual threading, diameter acceptance, controlled cooldown과 emergency shutdown을 포함한다.

허용 입력은 금속·label·cap·neck ring·adhesive·잔류물이 제거된 순수 PLA 또는 세척·건조된 PET뿐이다. UNKNOWN/REJECT override는 사용자가 재질을 물리적으로 확인한 경우에만 허용하며 classifier confidence를 숨기지 않는다.
