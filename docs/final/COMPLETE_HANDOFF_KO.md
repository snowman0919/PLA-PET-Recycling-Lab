# PPR 전체 인수인계 - v1.0.0-rc1

이 배포는 하나의 최종 제품을 제작하며 검증하기 위한 **디지털 제작 후보**다. 별도 간이 MVP를 만든 뒤 검증을 생략한 최종품을 만드는 방식이 아니다. 사용자 요청에 따른 공개 배포와 실제 구매·가공·통전 승인은 서로 다르다. 실물 시험은 NOT_RUN, 안전 인증은 NOT_CERTIFIED다.

## 1. 무엇부터 열어야 하는가

완전 패키지 압축을 풀고 최상위 `START_HERE.html`을 연다. 인터넷 없이 전체 모델 이미지, 문서 바로가기, 파일 검색을 사용할 수 있다. Python이 있으면 먼저 `python3 verify_package.py .`로 모든 파일의 SHA-256과 경로를 확인한다. 태그와 외부 SHA256SUMS도 대조한다. 해시 일치는 파일 동일성이지 기계 안전 인증이 아니다.

`repository/`는 원래 저장소의 상대경로를 그대로 보존한다. 소스·가공품·펌웨어·PDF·검사 템플릿을 다른 폴더에서 수동으로 조합할 필요가 없다. 별도의 FABRICATION ZIP은 작업별 자료 묶음이고 PHYSICAL-VALIDATION-LAUNCH ZIP은 현장 준비 자료다. 실행과 전체 재현의 기준은 완전 패키지의 `repository/` 또는 같은 Release 태그의 Git 체크아웃이다.

## 2. 설계·문서의 우선순위

**전체 기계 배치는 `exports/final/drive_ggm_v08/GGM-FULL-ASM.step` 및 같은 이름의 FCStd를 사용한다.** 이 모델의 외형은 470 x 729 x 930 mm다. 470 x 700 mm는 기본 프레임 치수다. `exports/final/step/assembly/PPR-FULL-ASM.step`은 GGM 통합 전 기본 형상의 소스·검증 기준으로 남겨둔 모델이며 최신 전체 배치가 아니다.

구동계 제작은 `exports/final/manufacturing/drive_ggm/`의 R2 도면과 manifest를 우선한다. EX-SCR-01/EX-THR-01의 GGM 도면은 별도 수량이 아니라 해당 부품의 구동단·지지부 변경이다. DRV-01/02/A60/F01 계열과 과거 GMP60 배치를 다시 채택하지 않는다. 분쇄기 12T/30T sprocket은 구매 기준 형상이지 치형 가공용 원본이 아니다.

부품별 명시 치수·공차·재료·표면처리·검사 요구사항 > 해당 최신 STEP > DXF/STL의 순서다. 제조사 승인도면과 수령 증거가 필요한 구매품에는 화면상의 외형만으로 호환성을 부여하지 않는다. 서로 다른 revision이나 문서의 수치가 충돌하면 임의 평균·현장 가공으로 맞추지 말고 해당 부품만 HOLD하여 설계 변경으로 해결한다.

## 3. 실제 제작 경로

P1 재고·수령과 길이 실측을 먼저 기록한다. P2에서는 해당 실측에 맞는 프레임·냉간 조립을 진행한다. P3 GGM 구동·전류/토크·전단핀 시험과 P4 두 장 cutter 검증을 거쳐 나머지 cutter를 제작한다. P5 동일 heat/공정의 screw/barrel coupon 합격 후 본품 공정을 확정하고 P6에서 본품 냉간 fit을 검사한다. 검증되지 않은 고가 본품을 먼저 전량 주문하지 않는다.

P7 안전회로 logic-only, P8 모터 한 축씩 무부하, P9 모터를 격리한 빈 hot-zone 가열 순서로 진행한다. 이후 P10 PLA, P11 PET, P12 냉각·측경·인장·권취를 검증한다. 단계별 정확한 선행 release, 계측 범위, U95, 중단 조건과 기록 양식은 `validation/physical_v08/PHYSICAL_EXECUTION_INDEX_KO.md`에서 찾는다. smoke 합격을 내구성·생산성·안전 인증으로 확대하지 않는다.

## 4. 기록·수정·재시험

시험마다 기계/부품 ID, source commit, 가공/열처리 lot, 계측기·교정, 작업자·독립 검토자, 시간대 포함 시각, 원시 사진·영상·CSV 경로와 SHA-256을 기록한다. 템플릿의 NOT_RUN을 증거 없이 PASS로 바꾸지 않는다. 실패한 구획과 그 후속 작업을 중지하고 원시 증거 보존, 원인 분석, CAD/BOM/전기/펌웨어 변경, 영향받는 디지털 검사 및 동일 실물 재시험 순서로 처리한다. 장공·shim·토크·센서 위치의 변경도 설계 기록 대상이다.

## 5. 아직 정해지지 않은 것

`open_items_ko.md`는 배포 시점의 제한과 실물 입력 목록이다. 가공 공정 증명, donor/구매품 identity, 교정값과 물리적 성능은 설계 파일만으로 만들어낼 수 없다. 동일한 문서·형상을 복원할 수 있도록 제공하는 것이며, 모든 부품의 조달 가능성이나 동일한 최종 성능을 무조건 보장하는 배포가 아니다. 재현 명령과 도구 조건은 `package_replay_ko.md`, 현재 스펙은 `product_specification_ko.md`를 따른다.
