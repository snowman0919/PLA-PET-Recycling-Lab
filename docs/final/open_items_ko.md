# 미해결 입력과 배포의 경계

이 목록은 공개 배포를 막기 위한 형식 목록이 아니라, 같은 형상으로 제작하더라도 결과가 달라질 수 있는 실제 입력의 목록이다. 자료가 없는 값을 만들어 채우거나 PASS로 승격하지 않는다.

| 구획 | 아직 필요한 실제 증거 | 해당 작업의 경계 |
|---|---|---|
| GGM / donor / 구매품 | 라벨·정격·serial·축/PCD/편심·단자·센서·체결 사양 | P1 실측 전에 최종 hole/adapter·핀 할당·통전 확정 금지 |
| 프레임 / 전체 배치 | 유효 stock 길이, kerf, 지지·고정, 장착 외형 및 접근 공간 | 최신 GGM 모델은 Y729 mm; 기본 프레임 Y700과 구분 |
| 형상 계보 | 기본 CAD와 GGM 추가 설계는 별도 검증 계보 | GGM manifest의 NEW_DRIVE_CLEARANCE_PASS는 새 간섭 검사이며 상속 접촉의 안전 인증이 아님 |
| Screw/barrel 공급망 | 같은 heat와 Q&T/질화/후가공 경로, 경도·유효층·조도·치수 검사 | JLCCNC는 현 SCM440/Q&T/질화 사양의 일괄 공급처가 아님; P5 승인 전 본품 전량 주문 금지 |
| 보호 핀 / 구동 | lot별 실제 파단 torque 분포, 전류-토크 관계·오차·RPM | 수치 목표만으로 운전용 보호 장치 합격 판정 금지 |
| 고온부 | 접합면·체결 예압·열팽창·간섭·heater 접촉·센서 응답·누설 | P9 빈 가열은 polymer 누설 시험이 아님; P10 별도 |
| PI 테이프 | 정확한 제조사/접착제/lot/두께·정식 정격, 같은 롤 coupon 기록 | 220 C는 판매자 주장 하한에서 정한 잠정값. 600 s smoke가 연속 정격·난연·전기절연 안전 인증을 증명하지 않음 |
| 테이프의 실제 효용 | 동일 조건의 무부착/부착 온도와 센서 부착 방법·불확도 | 바깥 표면 한 지점만 낮다고 차열 성공·내부 온도 안전으로 판정하지 않음 |
| 전기 | 수령품 DC 차단 정격, PE·절연·배선·interlock·수동 재시작 시험 | 논리 시뮬레이션을 접점 용착·단락·EMI 실제 시험으로 대체 금지 |
| 측경 / 권취 | 교정·반복성·장력·slip·1 kg 경로·실제 throughput | 목표 치수와 권취량은 실측 달성 보증이 아님 |
| 수명 / 인증 | 피로·마모·장시간 연속운전·유해 방출·정식 위험성 평가 | 이 prerelease는 인증서·완제품 출하 승인서가 아님 |

## 재현 범위

파일 동일성, 소스와 문서의 추적성, 현재 계약·회귀시험, native/STEP 정합성과 고정 도구의 펌웨어 재빌드는 디지털로 확인한다. 가공품의 공정 적합성과 계측 기반 운전 교정은 해당 실제 부품으로 완료해야 한다. 사용자 승인 없이 자동 가공·구매·통전하지 않는다.

## 실패를 처리하는 방법

영향 구획과 그 후속 단계만 HOLD하고 독립된 제작 작업은 계속할 수 있다. 원시 데이터를 보존하고 형상·재료·배선·제어 설정 중 원인을 특정한다. 설계 변경을 커밋하고 영향을 받는 도면·BOM·evidence binding을 갱신한 후 같은 최종 기계에서 재시험한다. 설계 변경 없이 임계값을 느슨하게 하거나 결과에 맞춰 시험의 합격 기준을 사후 변경하지 않는다.

전체 폴더에 남은 구형 v0.6/Fusion/실험 자료는 소스 계보 보존용이다. `COMPLETE_HANDOFF_KO.md`와 Release 첫 화면에서 지정한 현재 파일만 제작 인수인계 기준으로 선택한다. 포장·파일 무결성의 PASS와 미확인 물리 항목의 HOLD는 모순이 아니라 서로 다른 판정이다.
