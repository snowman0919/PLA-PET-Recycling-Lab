# 정비 원칙 — pre-release

- cutter, screen, feeder와 die는 독립 분리·청소 가능해야 한다.
- 정비 전 `docs/safety.md`의 lockout을 따른다.
- cutter edge, key/keyway, bearing play, guard/interlock, heater wiring, thermal fuse, puller roller, optical window와 fan/filter를 주기 점검한다.
- 실제 주기는 endurance 시험과 contamination log 전에는 확정하지 않는다.
