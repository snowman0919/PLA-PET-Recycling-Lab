# 결정 기록 — 저비용 1.75mm 필라멘트 품질 우선 경로
검토일: 2026-09-27
상태: 초기 비교 기준 선정. 물리 검증/견적 완료 또는 전역 경제 최적점 확정이 아니다.
정책은 루트 KODEX.md가 우선한다. 이 문서는 근거와 선택지를 보존하며 새 승인 사다리가 아니다.

## 1. 사용자 결정과 작업 상태
- 최종 목표는 폐출력물/purge에서 실제로 쓸 수 있는 균일 직경 필라멘트다. 분쇄와 프로브 이송은 수단이다.
- 전체 제품을 먼저 만들고 실제 형상 시험으로 개선한다. 최종 제품에 사용할 동일 압출 모듈의 기준 원료 주입은 허용하되, 상류 성공이나 임시 폐기형 시제품으로 취급하지 않는다.
- 초기 직경 설계 목표 1.75±0.05mm, 개선 목표 ±0.03mm. 물리 달성 여부는 미확인이다.
- 검토 당시 로컬/PR HEAD b1e02a99c672cfff1b5311668656f407c06f1707. 기준안/재배치안 모두 동일 입자의 버퍼 목 연결 0/200, 직경 측정 기반 필라멘트 생산은 미입증이다. 과거 로컬 변경과 시험은 STATUS/원자료에서 다시 확인한다.
- 500W hard cap, 본체700×420×520mm, 전체 추가비10만원 soft limit, M1 공유/M2 별도 유지. 단계적 동작으로 전력·공급을 분리할 수 있으나 모터·안전·유량 가정을 감추지 않는다.
- 사용자가 본 “1.75mm 커스텀 노즐 반복 통과” 영상은 링크/제작자를 확인하지 못했다. 특정 YouTube 프로젝트로 동일시하지 않는다. 영상 확보 전에도 비교 가능한 정형 경로를 검토한다.

## 2. 조사에서 실제로 확인한 것
[S1] Felfil의 공식 제품 설명은 냉각 후 직경 측정, 측정값에 따른 풀러 속도 조정, 권취 클러치로 장력 분리를 설명한다. 원리 참고이며 제품 구매 또는 판매자의 정밀도를 PPR 달성값으로 인용하지 않는다.
[S2] Filabot은 균일 직경을 위해 용융 온도, 냉각, 인출/권취 속도를 함께 조절하고 인라인 측정으로 확인하는 운영을 설명한다.
[S3] InFiDEL은 저비용 보정형 직경 센서의 공개 설계다. 원래 프린터의 유량 보정용이므로 압출 제어기로 그대로 동작한다고 가정하지 않는다. “<$5”는 프로젝트의 공표 비용이지 현재 한국 배송 포함 2축 계측계 견적이 아니다.
[S4] Petsiuk/Pearce의 공개 연구는 다축 광학 직경·표면 관측과 스풀 길이별 결함 기록을 다룬다. 저비용 카메라 경로의 근거지만 PPR의 정확도·투명재/TPU 적합성은 별도 확인이다.
[S5] Filastruder는 PLA 건조·냉각, 원료 크기·오염 관리와 반복 열이력을 주의사항으로 제시한다. 이 제조사의 5mm 투입 규격이나 사용자 공차 보고는 해당 기계의 사례이며 PPR 사양이 아니다.
[S6] Recreator3D는 PET#1 병을 대상으로 한 재사용 부품 기반 pultrusion이다. 불규칙 PLA/PET/TPU 출력물·purge를 모두 처리하는 PPR의 대체안은 아니다.

## 3. 현재의 가성비 유력 기준안과 비교
A. 단일 패스 용융 압출 + 가변 냉각 + 저가 직경 폐루프 + 독립 장력 권취
- 기존 설계의 단축 스크루/히터/풀러 **형상·인터페이스만** 후보로 재사용한다. Chiron 도너 PSU/프레임/모터·가이드/팬·열부품의 개별 치수·정격·제어 인터페이스가 맞을 때만 실물 재사용으로 배정하고, 부족하거나 부적합한 부품과 가공만 신규 견적에 넣는다(§6). 건조·선별과 공급 안정화, 교체 가능한 다이, 필요할 경우 지지된 멜트 필터를 포함한다.
- 정상 온도/스크루 속도를 안정화하고 냉각 후 직경의 오차를 풀러 속도로 보정한다. 권취 반경 변화가 인출 속도를 결정하지 않도록 장력을 분리한다.
- 2축 저접촉력 Hall/레버형과 공개 광학 방식을 후보로 두며 교정·표면 마찰·TPU 변형·투명재·전자부품/기구 비용을 비교한다.
- 지금 가장 먼저 구현·비교할 구조다. 아직 견적 또는 실물 검증으로 경제 최적점이 확정된 것은 아니다.

B. 추가 가열 정형 다이/노즐
- 사용자가 제안한 방식의 비교 경로다. 입력이 용융물, 이미 굳은 스트랜드, 병 스트립 중 무엇인지부터 구분한다.
- 기본 압출 후 0회/추가1회 정형을 먼저 비교한다. 반복 횟수 증가는 품질 이득과 에너지·수율·열이력·운전 부담의 근거가 있을 때만 한다.
- 다이 입구 테이퍼/랜드/실제 보어 공차/온도/인출/냉각 조건을 변수로 다룬다. 구멍이 1.75mm라고 냉각 후 직경이 자동으로 같아진다고 가정하지 않는다.
- 얇은 구간·기포·오염·타원도까지 자동 복원된다는 주장은 금지한다. 재가열 자체가 무조건 해롭거나 유익하다고도 단정하지 않는다. 수지 등급·건조·체류·열이력을 기록한다.
- 현재는 미검증 가설이다. 사용자 원영상이 확보되면 그 공정을 다시 분류하되 연구 전체를 멈추지 않는다.

C. 동일 하드웨어의 정속/수동 측정 운전
- 별도 폐기형 MVP가 아니라 A의 기본 운전 모드다. 센서 피드백의 품질·폐기율 개선이 추가 BOM보다 유리한지 같은 원료/목표속도로 비교한다.
- 센서 고장 때 계속 정상 생산으로 처리하는 대체 운전은 아니다. 계측 불가 구간은 격리/미확인으로 기록한다.

PET병 스트립 전용기, 고가 레이저 게이지/멜트펌프/진공 정형은 범위·가격 비교 대상이다. 원료 범위를 포기하거나 고가 보조장치를 기본 구매하는 선택은 하지 않는다.

## 4. 간단하지만 제품과 연결된 모델
냉각 후 고체 단면에 대해 질량수지:
mdot = rho_s * A_final * v_line
원형 근사: d_final = sqrt(4 * mdot / (pi * rho_s * v_line))
타원 근사: A_final = pi * dx * dy / 4.
이 관계는 유량·선속도가 흔들리면 최종 직경도 바뀐다는 뜻이며 노즐 보어만으로 최종 직경을 정할 수 없음을 보여준다. rho_s는 냉각 후 밀도다. 용융 체적유량과 혼용하지 않는다.
열/점도/다이 출구 변형/냉각 수축은 별도 불확실성으로 둔다. 알려지지 않은 값을 맞춰서 가상 합격을 만들지 않는다.
실제 다이 출구 x540→게이지 x809의 269mm가 피드백 사장거리다(PLA 100g/h·9.313mm/s 가정 시 약 28.9초). 게이지→니프 x829의 20mm는 이미 형성된 재료의 수송거리이지 제어계 입력 지연을 대신하지 않는다. 모터 응답·미끄럼·결측을 분리한다.
3구역 100W 밴드는 30초 슬롯에서 1기만 요구하고 60W 다이 카트리지와 온도·유량 민감도를 함께 스크리닝한다. 이 슬롯의 접점 수명과 교란 열회복은 미검증. 스풀 모터-샤프트-마찰 클러치-플랜지/드럼의 실제 토크·축방향 예압은 선정 전이며, 샤프트 홈·분할 링·와셔의 공칭 형상 접촉은 토크 정격 증거가 아니다.
Isaac은 제품 운동/공간/재료 이송에, 간단한 별도 공정 모델은 온도/유량/직경 제어에 사용한다. 이 모델이 실제 용융 FEM/CFD 해석이나 재료시험인 척하지 않는다.

## 5. 품질 측정과 가상시험의 경계
- 냉각·인출 후 상태의 1.75±0.05mm를 기본 목표로 한다. 평균만 보지 않고 각 측정축, 길이별 이탈·최대값·규격 내 길이, startup/reject/미관측 길이를 분리한다.
- dx/dy 두 축의 차이는 타원도 지표이지 임의 방향의 최대 타원도를 완전히 찾는 값은 아니다. 회전/다방향 표본 마이크로미터 대조를 후속 물리시험에 넣는다.
- 센서는 해상도와 정확도를 분리한다. 실제 기준물/마이크로미터 보정과 왕복 오차·온도 드리프트·스프링 접촉 변형을 검토한다. 초기 계측 불확실성 목표 U95<=0.01mm는 설계 가정이며 현재 성능 주장이 아니다.
- 원료별 건조/보관, 이물 선별, 기포·표면·취성, 필라멘트 질량/길이와 인출성을 함께 본다. PET!=PETG, TPU에는 압착·신장 영향이 크므로 원료별 제어 조건을 둔다.
- 가상시험: 공급 유량 변화, 온도 회복/냉각 변화, 센서 바이어스/누락, 풀러 슬립, 스풀 반경·장력 변화, 필터 막힘 신호, 500W 동시 수요를 넣고 정속 기준과 피드백을 비교한다.
- 미보정 모델의 규격 내 예측과 실제 규격 내 연속 길이는 다른 결과다. 실제 물리 출력을 이번 문서 변경으로 주장하지 않는다.

## 6. 경제성 및 다음 작업
목적은 처리량 최대화가 아니라 확보 가능한 품질에서 유효 생산량 대비 전체 비용을 낮추는 것이다. 후보별 추가 BOM/배송/가공, 규격 내 수율, 재작업/폐기, 에너지, 재료별 적용범위를 나란히 둔다. 수명·시간단가가 없으면 임의 상각비를 확정하지 않는다. 단품 광고가를 배송·가공 포함 시스템 견적으로 바꾸지 않는다.
현재 사용자가 재확인한 자산은 **2NC 비상정지 버튼 1개, 기존 Anycubic Chiron 도너 프린터와 그 PSU**다. 원본 저장소의 `bom/practical_mvp/policy.json`은 Chiron PSU를 24V 800W로 *과거 사용자 보고*했으나 명판 사진/모델이 없고, `validation/physical_v08/inventory_confirmation.csv`의 2020/2040 길이도 실측 재고가 아니다. 현행 모델의 240×120×65mm PSU 외형과 500W 운전 상한 역시 도너 명판·치수·상태·보호 및 부하 적합성을 입증하지 않는다. 버튼의 모델·접점 정격·강제개리·독립 하드컷 회로도 미확인이다. 기존 Chiron의 프레임 프로파일, 가이드, 스테퍼, 팬/히터/센서 등은 가능한 재사용 *대상*이지만 각각 길이·치수·신호(STEP/DIR 스테퍼를 PWM/DIR 풀러/권취로 간주 금지)·내열/전류·상태를 확인하기 전에는 현행 적격 BOM 재고로 배정하지 않는다. 원본의 과거 PLA/ABS 필라멘트 기록은 별도 기준 원료 펠릿의 보유 근거가 아니다. C1 인계의 '보유·0원' 나머지 9행은 자동으로 0원 처리하지 않는다. 활성 `system_bom.csv` 210행은 모두 착지가격 미견적(버튼/PSU 2행은 재구매 불요 *조건부*, 사용 적격 HOLD)이고 총비용은 미정이다. 과거 모터 후보 110,200원은 100,000원 전체 soft limit 대비 그 후보 하나만 10,200원 높다. 동일 최종 제품의 기준 펠릿 입력→압출→조절 냉각→직교 직경 계측→인출→장력 분리 권취를 먼저 검증하고 S1/S2 연결을 병행하되, 단계 구매가 전체비용 절감이나 안전부품 생략을 뜻하지 않는다.

실행 근거: `c2.1/results/downstream_route_comparison.json`, `c2.1/results/power_sim.json`, `c2.1/results/firmware_build.json`, `c2.1/bom/quality_component_candidates.csv`. 아래는 모두 **미보정 가상 민감도**이며 실제 필라멘트 성능·수율 또는 물리 제작 승인 결과가 아니다. 90초 정상 가상 운전의 니프 도달 부분은 C/A 모두 규격 내지만, 각각 약 290mm는 종단에서 다이→니프 사이에 남아 미확인으로 차감된다. C에도 사후 평가용 같은 2축 센서 신호를 가정하되 제어에는 사용하지 않았다. 가상 모델이 과거에는 **참 직경 2축만** 규격 안이면 편향 게이지가 범위 밖으로 표시해도 합격 길이로 셌다. 100g/h·70초·고정속도 PLA에서 참 직경 1.75mm, 양 계측축 1.85mm(+0.10mm 편향)의 니프 도달 362.29mm 전량이 잘못 합격했으나, 현행 판정은 참 직경 두 축과 측정 두 축이 모두 1.70..1.80mm·축차≤0.05mm이며 냉각 완료일 때만 인정해 이 경우 0mm다. PI 입력은 두 계측축의 면적등가 직경으로 C++ `controller_core.cpp` 커널을 호출한다. 모델의 `sensor_dropout`은 새 표본 없음으로 취급해 운전 중 1초 초과 시 중단하고, `sensor_major_dropout`/`sensor_minor_dropout`은 명시적 불량 축으로 취급해 첫 운전 중 불량 입력에 즉시 중단한다. 기존 40..40.4초 단일축 불량을 1초 표본 부재로 뭉뚱그리면 끝까지 운전했지만 현행 모델은 40.0초에 중단한다. 펌웨어는 운전 중 불량 축/오래된 표본을 `quality_hold`에 래치하고 수동 리셋 전 자동 재기동을 거부한다. 가상 모델은 펌웨어 전체 I/O·보호/전력 배분 실행이나 실제 재기동 잔재를 재현하지 않는다. 단면 두 축 계측만으로 최대 타원도나 교정 정확도를 증명하지 않는다.

실제 2축 센서 인터페이스는 미구현이다. 한 축 불량을 C++ 입력의 `gauge_valid=false`로 전달한다는 계약이 충족되어야 위의 즉시 HOLD와 같아지며, 센서 드라이버·배선·실물 안전회로의 연동은 별도 검증 전까지 HOLD다.

기존 복합 교란의 클러치 고장은 170..178초이나 피드백 A는 계측 누락으로 146초에 이미 정지하므로 그 실행에서 피드백의 권취 고장 반응을 시험했다고 주장할 수 없다. 별도 `clutch_fault` 실행은 같은 8초 고장을 결측 없이 양쪽 경로에 적용했다. 위의 규격 내 길이는 니프 도달 모델 결과이며 종단에 남은 약 290mm는 미확인으로 제외한다. 70Nmm 클러치, 8N 인출 그립 경계 및 초과 장력에 대한 슬립률은 선정/교정된 실제 값이 아니다.

냉각 민감도: 가정한 유효 강제대류 길이 250mm일 때 PLA 2팬 게이지 중심 53.80°C(가정 준비 한계55°C, 여유1.20°C), 3팬 44.64°C. TPU 2팬 60.28°C(가정 한계50°C, 불합격), 3팬 48.46°C(여유1.54°C). PET는 같은 모델 2팬 45.89°C, 3팬 39.14°C. 팬의 압력-유량·공기 흐름·수지 물성과 광학/접촉계측 편향은 측정하지 않았다. 기존 남쪽 팬 두 대의 막힌 트레이 벽에 78×21mm 창 두 개, 가동 후드 상부에 Ø70 관통구와 분리형 80×80×38mm 팬 참조를 추가해 **공기 통로만** 형상 검증했다. 100mm 후드 이동이 가정한 50..250mm 유효 대류 길이를 구현한다는 증거는 없다.

인출 롤러가 원래 필라멘트 y275의 *끝면*에 닿던 결함을 수정해 22mm 폭 중앙(y264..286)에 선을 놓고 양쪽 롤러의 1.75mm 접촉과 베어링 보어/정지좌 무간섭을 BRep으로 확인했다. 마찰력·TPU 찌그러짐·스프링 압력은 미검증. 권취 샤프트의 헐거운 드럼 보어는 구동이 아니므로 키드 칼라→스프링 자리→마찰 패드→플랜지 경로를 별도 CAD로 배치했다. 기존 형상은 플랜지가 오른쪽으로 3mm 이동해도 샤프트·베어링·클러치에 BRep 접촉이 없었다. 초기 Ø14.4 홈뿌리/Ø24 분할 링 후보는 시판품 치수와 불일치했다. 현행 디지털 후보는 Ø16 샤프트 y96..97/y168..169의 폭1mm·Ø15.02 홈과 ES-16 공칭 링 외형 포락선(2회 감김 실제 형상 아님), 오른쪽 플랜지 y167..168의 Ø30/Ø16.2 와셔다. 오른쪽으로 밀린 플랜지→와셔→링→샤프트의 이탈 정지 경로만 형상으로 확인했고, 링과 칼라/와셔 사이에는 공칭 면간격이 있다. 클러치 예압·토크·70Nmm 가상 모델값/반경별 약2N 장력은 실제 정격이 아니다.
추가로 이전 `PULL_ROLLER_ADJ`는 롤러·캐리지·횡방향(Y축) 스프링/포스트를 하나의 강체로 융합한 CAD였다. 위의 정지좌 필라멘트 교차는 니프의 수직 순응이나 독립 회전을 증명하지 못했다. 현행 후보는 Ø20 아이들러+Ø6 축을 별도 회전체로 분리하고, 두 Ø6.04 베어링 보어 포락선의 `PULL_IDLER_CARRIAGE`가 프레임의 Ø5 수직 가이드 두 곳을 따라 1.5mm 움직인다. 하부/상부 금속 정지좌가 니프 1.5..3.0mm를 제한하고 두 `PULL_IDLER_SPRINGS`의 축방향 **공간 포락선**은 그 사이 설치 높이 8.5→7.0mm를 나타낸다. 공칭 축-보어 반경 간격 0.02mm도 공차·부싱/베어링·런아웃을 제외한 CAD 간격일 뿐, 교정된 필라멘트 허용 편차나 회전 수명 근거가 아니다. 니프 세 위치(최소/공칭 필라멘트/최대)에서 회전체·캐리지·스프링·프레임/정지좌 BRep 무간섭 및 분리 회전 경로만 확인했다. 30N 아이들러 축 굽힘은 가상 하중 감도 분석이고 실제 스프링 자유/솔리드 높이·예압·접촉력·TPU 압착·풀러 미끄럼과 실제 축추력·체결/비용은 **미선정/미검증**이다. `winder_geometry.json`의 `geometry_passed`와 `path_check.json`의 `all_nip_geometry_clear`는 물리 니프 그립 합격이 아니다.
초기 분리안은 새 캐리지/정지좌/축이 미선정 풀러 모터의 y232..248 Ø16 노즈와 1.77..54.61mm³ 범위로 겹쳤다(위치별 BRep). 축/캐리지의 첫 면을 y249로 물리고 프레임 옆판을 y259..263/y287..291로 조정하여 회전체 y264..286와 양쪽 1mm, 모터 노즈 끝 y248와 이동축 시작 y249 사이 **공칭 1mm** 간격을 확보했다. 이 역시 실제 모터축/벨트·마운트/공차/편심을 포함하지 않는 후보 간격이다.
USD에는 이 스프링 공간 두 곳을 **시각 전용/충돌 비활성** 형상으로 남긴다. 선택된 실제 스프링이 없으므로 `materials.py`에서 공칭 질량 0/강재 포락선 질량 상한으로 분리한다. 이는 구매비·실제 질량 0원/0g을 뜻하지 않으며, 부품표의 스프링 2개는 `UNQUOTED_NOT_ZERO`다. 모터·베어링·스프링 선정 후 CAD/질량/간섭을 다시 산정해야 한다.

ES-16 제조사 명세[S7]: 홈 Ø15.02±0.075mm, 폭1.00+0.08/−0.00mm, 링 축두께0.89±0.05mm, 반경 방향 벽1.40+0.08/−0.13mm, 자유 상태 내경14.90+0/−0.33mm. 설치 링의 단순 환형 외경 공칭 약17.82mm이므로 초기 Ø24 보유력 모델을 폐기했다. 홈-링 축유격은 **한쪽 0.06..0.24mm, 두 곳 합계 최악 0.48mm**(다른 축 스택 공차·열팽창·탄성은 제외). 와셔의 Ø16.2 공칭 보어와 링 최소 외반경8.7425mm에서 와셔 편심0.1mm를 *가정*한 반경 겹침 하한0.5425mm는 와셔 보어/샤프트 제작 공차가 빠진 조건부 기하 스크리닝이지 압력면·하중 정격이 아니다. 제조사 홈 항복3820N은 홈 재질 항복45,000psi/안전계수2 조건, 링 전단14,900N은 안전계수3 조건이며 PPR 재질·축피로·조립/베어링·반복 슬립이 검증되지 않아 적용하지 않는다. 링 MPN은 **치수 참조**일 뿐 선정/견적/주문이 아니다.
SSB-0087[S8]은 Ø16.46 축을 피하지만 공표 하중62.3N의 **작업 높이1.57mm**는 현행 미선정 스프링 자리1.00mm보다 **0.57mm 크다**. 1mm로 압축 가능한지, 솔리드 높이·영구변형·하중은 해당 자료에서 확인하지 못했다. 이 스프링을 CAD에 끼워 넣거나 62.3N을 예압으로 채택하지 않았다. 홈 유격까지 고려한 스프링 길이 조정·마찰계수/토크 측정과 washer/링/홈 공차·피로·베어링 축추력 평가 없이 권취 운전 HOLD. 두 공급품 모두 착지·가공 단가 미확인이라 0원 처리하지 않으며, 최소 기능 비용안도 미확정이다. 근거 화면 `c2.1/results/winder_geometry.json`의 `retention_fit_screen`; 업체 카탈로그값과 가상 CAD를 물리시험으로 오인하지 않는다.
권취 조립의 제작 경로 점검에서 기존 베어링 좌석(x688..712)과 모터(x680..720)가 프레임 최대 x630 밖에 떠 있는 결함을 발견했다. 같은 제품의 `WIND_MOUNT`는 앞쪽 알루미늄 20mm 직립재의 y60면에 Ø5.5 관통 후보 구멍 두 개로 닿고, 플랜지 회전면 바깥(x590..600)을 경유하는 두 강재 레일이 양쪽 베어링 바닥에, 별도 하부 받침이 모터 바닥에 접한다. CAD의 면 접촉·간섭 부재는 실제 볼트 체결·모터 선정·피로/진동 강도 증명이 아니다. 도너 프로파일 또는 부족분 신규 조달재의 슬롯/웹과 볼트·용접·베어링 사양을 확정하기 전 가공/권취 운전 승인 HOLD. 드럼은 과거 Ø70 외경-Ø17 내경의 거의 실심 강재 링(약 1,649g) 대신 2mm 강관과 두 3mm 내부 허브 웹(약 345g)으로 형상을 바로잡았다. 후보 강재 밀도 7.85g/cm³로 두 3mm 플랜지 포함 회전 스풀은 3,117.86→1,813.98g(-1,303.88g, 약 -41.8%), 정지 강재 마운트는 약 0.30kg 추가다(`c2.1/results/winder_geometry.json`). 이 수치에는 권취 필라멘트, 모터·체결재·용접 비드, 실제 재료/공정 손실이 없으며 질량 절감이 제조 단가 절감을 뜻하지 않는다. BOM의 마운트/웹 제작·구매·배송은 미견적이고 모터 한 후보 110,200원은 이미 전체 100,000원 soft limit를 초과한다. 적재·강성·허용 편심과 정지/시동 클러치 토크·방호는 여전히 선정/실측 대상이다.
인출 프레임도 기존에는 x822..846으로 끝나는 냉각 트레이 x820과 2mm 이상 떨어져 있고 트레이 자체도 후면 프레임 y360에서 끝나는 판재 y315까지 간격이 있어 하중 경로가 없었다. `PULL_COOL_MOUNT` 후보는 후면 Al 직립재 x630면의 Ø5.5 후보 구멍 네 개→20×20×2mm 강재 사각관 x634..836→18×16×2mm 인출 받침관 x824..842의 연속 금속 경로로 프레임 바닥 z100에 닿는다. 별도 강재 받침 x545..820, y300..315, z95..103은 2mm 냉각 트레이 바닥에 면접촉한다. 풀러 프레임과 받침에는 동일한 Ø4.5 관통 후보 구멍 두 개를 배치했다. 롤러 하부와 0.25mm 밖에 떨어지지 않아 볼트 머리는 면 아래에 매입해야 하나 실제 체결재는 미선정이다. 이 후보 랙은 밀도 7.85g/cm³ 가정 시 약 0.707kg의 추가 정지 강재; 권취 마운트 약 0.295kg과 합산 약 1.002kg이고, 스풀 회전 질량 절감 1.304kg과 상쇄해 원가 우위로 해석하지 않는다. 프로파일 슬롯, 실제 냉각 트레이/팬·계측계 체결, 용접/체결 토크, 장거리 캔틸레버의 동적 강성과 제작비는 별도 HOLD다. 랙 형상 접촉·간섭 시험은 가공 허가가 아니다.

전력은 M1 196.8W, M2 43.2W, 3팬 24W가 **미선정/추정**, 히터 단일 밴드100W + 다이60W가 이름표 기초다. 전체 동시 기준부하 424W이며, 500W 상한에서 풀러+권취+부가 구동에 히터를 유지하려면 최대 76W만 남는다. `power_sim.py`의 444W 피크는 임의 **20W 보조부하 시험 입력**을 더한 값이고 실제 정격/구매안이 아니다. 보조부하 미확인 또는 상한 거부 시 호스트 컨트롤러 M2를 정지시킨다. 150W를 주면 밴드가 거부되어 열회복을 보장할 수 없다. 30초 슬롯·보호 릴레이 선정/온도 회복은 별도 시험 HOLD.

센서/품질 비용 후보(판매자 공개 단가, 2026-09-27 조회; 배송/부가세/관세/가공/보정·환율/착지가격은 미견적): Hall 레버 2축안은 Adafruit TMAG5273A1 보드 두 개 $11.90 **전자부품만**; 출구 형상에 넣은 혼합 1 Hall+1 광학안도 두 축 모두 교정 전 HOLD. TSL1401CL 광학 2축안의 모듈 두 개 R1,350(현지 세전), 128픽셀/8.12mm ⇒ 센서면 피치 약0.0634mm로 물체면 정확도 주장이 불가하다. 1.75mm 단일 기준핀 £14.712001와 Fowler 마이크로미터 $52도 각 판매자 공개 단가일 뿐이며 추가 기준핀/교정증명 미포함이다. 나열한 통화는 서로 합산하지 않는다. 미보유 모터 후보만 110,200원으로 이미 10만원 soft limit 초과; 추가 센서·구동·배송비를 0원으로 넣을 수 없다. 센서 없는 C가 낮은 초기비용이지만 편차 때 0mm인 모델 사례와 결측 중단 사례를 함께 보고 **정확도·착지가격·실제 길이당 품질 손실**이 얻어질 때만 A/센서 구성을 선택한다. 품절 RC 슬리퍼 클러치 £15.95는 전용 연속슬립 토크 정격이 없어 견적 근거에서 제외한다.

재가열 정형 패스 B는 압력·온도·열이력·형상 및 추가전력이 없어 **비순위 HOLD**. 보어가 1.75mm라서 결핍/기포를 메운다는 허구의 직경 배율을 삭제했다. 상류 수용 유량 100g/h는 원료 공급·스크루 실측 전 설계 목표, 허용 입도/건조 수분은 등급별 투입구·멜트 필터·압력/기포 시험 없이 4mm/200ppm으로 확정하지 않는다.


## 8. 상류 인계의 하류 기준과 검증 경계
단축 압출기 100g/h 설계 목표에서 **정속·동일 밀도·원형/무기포**만 가정하면 유량 변화에 따른 직경 1.70..1.80mm 창은 공칭 대비 약 -5.63..+5.80%다. 269mm 피드백 사장시간 동안 기준 유량에 해당하는 질량은 약 0.802g이며, 이는 **버퍼 최소 용량 설계 또는 실제 허용 요동 폭을 증명하지 않는다**. 순간 공급 중단·혼합재·스크루 압력/다이 온도·기포·편심은 추가 결함을 만든다. 원료 혼합 대신 재질/등급/열이력별 건조와 체과, 이물 제거·전달 유량·버퍼 질량 변동을 측정한다. S2 화면 nominal Ø4/스크루 채널 치수만으로 통과 플레이크의 장경·압출 적합성·200ppm 수분을 확정하지 않는다.

이전 `c2.2/results/full_machine/flow_localize/results.json`은 STEP `875551dd…`의 별도 국부시험이었다. S1 하부 통과 22개 중 메인 스크루 픽업 10, 전진 1, 실제 S2 입구 0; 좁힌 `chute_inlet`은 22개 중 입구 경로 2, 실제 S2 입구 0이다. 이 결과의 USD도 당시 STEP에서 변환됐으며, 이후 VP1 STEP에는 해시가 맞지 않는다. 새 형상은 `chute.py`에서 측면 이송 스크루 스윕 반경 6.7→7.2mm를 증대하고 바닥의 해당 금속을 **국소 릴리프**하여 x223/z336.5 부근 정체 Ø3mm 포락선에 닿게 했다. 부품/커터 스윕 무간섭과 인계 접근성은 정적 BRep·단위시험 수준. 축 토크·플레이크 실제 픽업은 증명하지 못했다. 동일 입자 S1→S2 **실제 보어**→스크린→버퍼 연결, 압출 유량 안정성과 폐원료에서의 규격 내 필라멘트 생산은 모두 HOLD다. NVIDIA EULA를 수락하지 않았으므로 새로운 Isaac native 시험을 강행하거나 과거 결과를 현재 형상의 결과로 재표기하지 않는다.
