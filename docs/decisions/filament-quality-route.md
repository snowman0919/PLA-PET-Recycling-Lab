# 결정 기록 — 저비용 1.75mm 필라멘트 품질 우선 경로
검토일: 2026-09-27

정책은 루트 KODEX.md가 우선한다. 이 문서는 근거와 선택지를 보존하며 새 승인 사다리가 아니다.

## 1. 사용자 결정과 작업 상태
- 최종 목표는 폐출력물/purge에서 실제로 쓸 수 있는 균일 직경 필라멘트다. 분쇄와 프로브 이송은 수단이다.
- 전체 제품을 먼저 만들고 실제 형상 시험으로 개선한다. 최종 제품에 사용할 동일 압출 모듈의 기준 원료 주입은 허용하되, 상류 성공이나 임시 폐기형 시제품으로 취급하지 않는다.
- 초기 직경 설계 목표 1.75±0.05mm, 개선 목표 ±0.03mm. 물리 달성 여부는 미확인이다.
- 검토 당시 로컬/PR HEAD b1e02a99c672cfff1b5311668656f407c06f1707. 기준안/재배치안 모두 동일 입자의 버퍼 목 연결 0/200, 직경 측정 기반 필라멘트 생산은 미입증이다. 과거 로컬 변경과 시험은 STATUS/원자료에서 다시 확인한다.
- 500W hard cap, 본체700×420×520mm, 전체 추가비10만원 soft limit, M1 공유/M2 별도 유지. 단계적 동작으로 전력·공급을 분리할 수 있으나 모터·안전·유량 가정을 감추지 않는다.
- 사용자가 본 “1.75mm 커스텀 노즐 반복 통과” 영상은 링크/제작자를 확인하지 못했다. 특정 YouTube 프로젝트로 동일시하지 않는다. 영상 확보 전에도 비교 가능한 정형 경로를 검토한다.

## 2. 조사에서 실제로 확인한 것
[S1] Felfil의 공식 제품 설명은 냉각 후 직경 측정, 측정값에 따른 풀러 속도 조정, 권취 클러치로 장력 분리를 설명한다. 원리 참고이며 제품 구매 또는 판매자의 정밀도를 PPR 달성값으로 인용하지 않는다.
[S2] Filabot은 균일 직경을 위해 용융 온도, 냉각, 인출/권취 속도를 함께 조절하고 인라인 측정으로 확인하는 운영을 설명한다.
[S3] InFiDEL은 저비용 보정형 직경 센서의 공개 설계다. 원래 프린터의 유량 보정용이므로 압출 제어기로 그대로 동작한다고 가정하지 않는다. “<$5”는 프로젝트의 공표 비용이지 현재 한국 배송 포함 2축 계측계 견적이 아니다.
[S4] Petsiuk/Pearce의 공개 연구는 다축 광학 직경·표면 관측과 스풀 길이별 결함 기록을 다룬다. 저비용 카메라 경로의 근거지만 PPR의 정확도·투명재/TPU 적합성은 별도 확인이다.
[S5] Filastruder는 PLA 건조·냉각, 원료 크기·오염 관리와 반복 열이력을 주의사항으로 제시한다. 이 제조사의 5mm 투입 규격이나 사용자 공차 보고는 해당 기계의 사례이며 PPR 사양이 아니다.
[S6] Recreator3D는 PET#1 병을 대상으로 한 재사용 부품 기반 pultrusion이다. 불규칙 PLA/PET/TPU 출력물·purge를 모두 처리하는 PPR의 대체안은 아니다.

## 3. 현재의 가성비 유력 기준안과 비교
A. 단일 패스 용융 압출 + 가변 냉각 + 저가 직경 폐루프 + 독립 장력 권취
- 기존 단축 스크루/히터/풀러 자산 재사용. 건조·선별과 공급 안정화, 교체 가능한 다이, 필요할 경우 지지된 멜트 필터를 포함한다.
- 정상 온도/스크루 속도를 안정화하고 냉각 후 직경의 오차를 풀러 속도로 보정한다. 권취 반경 변화가 인출 속도를 결정하지 않도록 장력을 분리한다.
- 2축 저접촉력 Hall/레버형과 공개 광학 방식을 후보로 두며 교정·표면 마찰·TPU 변형·투명재·전자부품/기구 비용을 비교한다.
- 지금 가장 먼저 구현·비교할 구조다. 아직 견적 또는 실물 검증으로 경제 최적점이 확정된 것은 아니다.

B. 추가 가열 정형 다이/노즐
- 사용자가 제안한 방식의 비교 경로다. 입력이 용융물, 이미 굳은 스트랜드, 병 스트립 중 무엇인지부터 구분한다.
- 기본 압출 후 0회/추가1회 정형을 먼저 비교한다. 반복 횟수 증가는 품질 이득과 에너지·수율·열이력·운전 부담의 근거가 있을 때만 한다.
- 다이 입구 테이퍼/랜드/실제 보어 공차/온도/인출/냉각 조건을 변수로 다룬다. 구멍이 1.75mm라고 냉각 후 직경이 자동으로 같아진다고 가정하지 않는다.
- 얇은 구간·기포·오염·타원도까지 자동 복원된다는 주장은 금지한다. 재가열 자체가 무조건 해롭거나 유익하다고도 단정하지 않는다. 수지 등급·건조·체류·열이력을 기록한다.
- 현재는 미검증 가설이다. 사용자 원영상이 확보되면 그 공정을 다시 분류하되 연구 전체를 멈추지 않는다.

C. 동일 하드웨어의 정속/수동 측정 운전
- 별도 폐기형 MVP가 아니라 A의 기본 운전 모드다. 센서 피드백의 품질·폐기율 개선이 추가 BOM보다 유리한지 같은 원료/목표속도로 비교한다.
- 센서 고장 때 계속 정상 생산으로 처리하는 대체 운전은 아니다. 계측 불가 구간은 격리/미확인으로 기록한다.

PET병 스트립 전용기, 고가 레이저 게이지/멜트펌프/진공 정형은 범위·가격 비교 대상이다. 원료 범위를 포기하거나 고가 보조장치를 기본 구매하는 선택은 하지 않는다.

## 4. 간단하지만 제품과 연결된 모델
냉각 후 고체 단면에 대해 질량수지:
mdot = rho_s * A_final * v_line
원형 근사: d_final = sqrt(4 * mdot / (pi * rho_s * v_line))
타원 근사: A_final = pi * dx * dy / 4.
이 관계는 유량·선속도가 흔들리면 최종 직경도 바뀐다는 뜻이며 노즐 보어만으로 최종 직경을 정할 수 없음을 보여준다. rho_s는 냉각 후 밀도다. 용융 체적유량과 혼용하지 않는다.
열/점도/다이 출구 변형/냉각 수축은 별도 불확실성으로 둔다. 알려지지 않은 값을 맞춰서 가상 합격을 만들지 않는다.
측정 지연은 배치 길이와 실제 선속도에 따른 이송 시간이다. 느린 제어기부터 사용해 수송 지연, 모터 한계, puller slip, 급격한 유량 변화와 windup을 시험한다.
인출 구동과 권취 장력, 500W 히터 스케줄과 온도 회복을 함께 모사한다. melt filter 차압·스크루/배럴 압력·추력·냉간 압출 방지는 설계 입력이며 공칭값으로 안전을 보증하지 않는다.
Isaac은 제품 운동/공간/재료 이송에, 간단한 별도 공정 모델은 온도/유량/직경 제어에 사용한다. 이 모델이 실제 용융 FEM/CFD 해석이나 재료시험인 척하지 않는다.

## 5. 품질 측정과 가상시험의 경계
- 냉각·인출 후 상태의 1.75±0.05mm를 기본 목표로 한다. 평균만 보지 않고 각 측정축, 길이별 이탈·최대값·규격 내 길이, startup/reject/미관측 길이를 분리한다.
- dx/dy 두 축의 차이는 타원도 지표이지 임의 방향의 최대 타원도를 완전히 찾는 값은 아니다. 회전/다방향 표본 마이크로미터 대조를 후속 물리시험에 넣는다.
- 센서는 해상도와 정확도를 분리한다. 실제 기준물/마이크로미터 보정과 왕복 오차·온도 드리프트·스프링 접촉 변형을 검토한다. 초기 계측 불확실성 목표 U95<=0.01mm는 설계 가정이며 현재 성능 주장이 아니다.
- 원료별 건조/보관, 이물 선별, 기포·표면·취성, 필라멘트 질량/길이와 인출성을 함께 본다. PET!=PETG, TPU에는 압착·신장 영향이 크므로 원료별 제어 조건을 둔다.
- 가상시험: 공급 유량 변화, 온도 회복/냉각 변화, 센서 바이어스/누락, 풀러 슬립, 스풀 반경·장력 변화, 필터 막힘 신호, 500W 동시 수요를 넣고 정속 기준과 피드백을 비교한다.
- 미보정 모델의 규격 내 예측과 실제 규격 내 연속 길이는 다른 결과다. 실제 물리 출력을 이번 문서 변경으로 주장하지 않는다.

## 6. 경제성 및 다음 작업
목적은 처리량 최대화가 아니라 확보 가능한 품질에서 유효 생산량 대비 전체 비용을 낮추는 것이다. 후보별 추가 BOM/배송/가공, 규격 내 수율, 재작업/폐기, 에너지, 재료별 적용범위를 나란히 둔다. 수명·시간단가가 없으면 임의 상각비를 확정하지 않는다. 단품 광고가를 배송·가공 포함 시스템 견적으로 바꾸지 않는다.
현재 모터 견적 110,200원은 한 후보일 뿐이다. 센서·히터·단열·팬·풀러·제어·보호를 포함한 예산 표에서 부족액을 드러내고 낮은 처리량/간단한 배치/보유품 재사용 대안을 제시한다.
다음 구현의 주축은 최종 압출 모듈의 실제 다이/열구역/냉각 길이/센서 설치/풀러/장력 분리, 직경 계측 인터페이스와 제어 코드, 동일 제품 공정 모델이다. 기존 원료 주입구/버퍼의 서비스 입력으로 건조 기준 원료를 명시해 하류 시험을 분리한다. 동시에 상류 수신 입도·수분·공급률을 하류 요구에서 정하고 이송계를 단순화한다.
도면/코드/시험은 선정된 전체 조립체에 재통합한다. 대규모 독립 물성/solver 연구, 새로운 승인 phase, 근거 없는 후보 증식은 하지 않는다. 상류 연결 실패, 물리 실험, 구매·통전·병합은 기존 경계를 유지한다.

## 7. 공정 모델 시뮬레이션 및 경로 비교 결과 (VP1 Stage 6)
실행 근거: `c2.1/results/downstream_route_comparison.json`, `c2.1/src/process_model.py`, `c2.1/src/route_comparison.py`.
공정 모델은 냉각 후 고체 단면 질량수지(mdot = rho_s * A_final * v_line), 집중 열용량 대류 냉각, 20 mm 실제 수송 지연(delay = 20 mm / v_line), 풀러 슬립 및 스풀 반경 증가와 500W 히터 스케줄(단일 100W 밴드 순환, 상시 60W 카트리지, 동시 전력 <= 160W)을 연계했다.

1. 시나리오 1: 과도 교란 (유량 급증 +35% 10초, 결핍 -29% 10초, 센서 편향 +15 um 40초, 센서 결측 5초, 장력 스파이크 10N):
   - C (정속 기준): 규격 내 길이 564.0 mm (수율 67.43%), 평균 직경 1.755 mm, 최대 2.033 mm, 최소 1.474 mm.
   - A (직경 피드백 PI): 규격 내 길이 496.2 mm (수율 58.91%), 평균 직경 1.749 mm, 최대 2.031 mm, 최소 1.445 mm.
   - B (피드백 + 가열 정형 가설): 규격 내 길이 540.6 mm (수율 64.19%), 평균 직경 1.750 mm, 최대 1.947 mm, 최소 1.536 mm.
   - 분석: +15 um 편향을 가진 센서와 20 mm 수송 지연 하에서 피드백 제어는 정속보다 낮은 수율을 기록했다. 센서 오차가 풀러 속도를 반대로 교란해 지연 위상차로 오차를 키운 결과다. 기준물(1.50/1.75/2.00 mm 핀 게이지)에 의한 영점 교정(U95 <= 0.01 mm) 선행 없이는 센서 추가가 오히려 필라멘트 품질을 악화시킨다는 점을 물리 모델로 입증했다.

2. 시나리오 2: 정상 상태 지속 오차 (+20% 유량 지속 오프셋):
   - C (정속): 규격 내 길이 0.0 mm (수율 0.00%), 평균 직경 1.918 mm로 규격 상한(1.80 mm) 완전 이탈.
   - A (직경 피드백): 수율 회복 시작, 평균 직경 1.836 mm로 목표 방향 지속 추종.
   - B (피드백 + 정형): 평균 직경 1.810 mm로 개선.
   - 분석: 원료 점도·온도 드리프트·노즐 마모 등으로 인한 지속 정상 오차에는 정속 제어는 전량 폐기(0% 수율)가 불가피하며, 폐루프 피드백만이 유일한 품질 복원 경로다.

3. 하류 모듈의 상류 이송계 수용 요구조건:
   - 공칭 유량: 기준 원료 PLA 기준 12 mm/s 인출 시 mdot = 0.0358 g/s (약 129 g/h).
   - 최대 허용 플레이크 입도: 스크루 피치 16 mm, 유효 채널 깊이 3 mm를 감안해 4.0 mm 이하 체과 플레이크 (권장 2.0~3.0 mm).
   - 수분 함량: PLA 가수분해 방지를 위한 함수율 <= 0.02% (200 ppm).
