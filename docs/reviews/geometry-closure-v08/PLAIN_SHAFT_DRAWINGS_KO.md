# 가이드봉·댄서 축 도면 보완

대상은 SP-TG-01(8 h6 x196, 수량2), SP-AX-01(8 h6 x38, 수량1), SP-AX-02(8 h6 x52, 수량1)이다. 현재 FreeCAD 제조 정의와 같은 원통 형상을 사용한다.

범용 edge 투상은 원통의 측면 실루엣을 누락해 측면이 선 하나처럼 보일 수 있다. 이 세 부품만 명시적 끝면/측면 윤곽, 중심선, 연장선, 지름 및 길이 치수선으로 표시한다. 길이/지름 비율은 실제 형상의 bounding box에서 읽는다. 가이드봉 길이의 기존 ISO 2768-m 일반공차와 댄서 축의 명시된 +/-0.10 mm를 유지한다. h6 지름 범위는7.991-8.000 mm이다.

구멍·단차·기타 가공 특징이 있는 형상에는 원통 실루엣을 적용하지 않는다. 부품ID, 솔리드/face 수, 원통 단면·체적 검사를 거쳐 다른 형상은 전용 도면을 요구한다. validation/test_manufacturing_projection.py는 기존 원형 tessellation/제목 공간 검사를 유지하고 세 실제 축의 비율·치수와 잘못된 단면/내부 보어 거부를 검사한다.

이는 축방향 유지력, 공차 실측 또는 제조 승인이 아니다. 현재 기계 전체의 고온부 qualification과 BOM root/detail 중복 해결은 별도이며 전체 Release는 HOLD다. 이 도면과 기존 공개 rc1 문서를 섞어 발주하지 않는다.
