# rc1 이후 수정본의 디지털 검토와 사용 제한

이 문서는 프로파일 축소, 트래버스/댄서 축 고정, Z1 폭/지지 위치 수정본에 적용한다. 기존 공개 v1.0.0-rc1 태그나 ZIP을 이동·덮어쓰지 않는다. 패키지 manifest의 source_commit이 실제 입력 기준이며, 구형 rc1 도면과 최신 일부 부품을 섞어 제작하지 않는다.

## 수치 검증과 설계 적합성은 다르다

Z1 모델의 `DIGITAL_DELTA_SCREEN_COMPLETE`는 수치 수렴·에너지 수지·분리 비교를 확인하는 상태다. 가열계의 정격 적합이나 통전 허가가 아니다. 실제 수치와 가정은 `analysis/thermal_revision_v08/README_KO.md` 및 해시가 일치하는 `hot_zone_revision_review.json`을 따른다.

- 기준 Z1 구간45..90 mm, 변경45..85 mm를 사용한다. 폭만/지지 위치만/동시 변경을 분리한다.
- 수정안 일부 가정에서 히터 lump 최고온도346.54 C가 나타났고 300 C 비교값을 초과했다. 300 C는 제조사가 승인한 외피 정격이 아니다.
- 1800초 내 목표 범위 도달은 수정안8조건 중3조건이다. 목표 미도달과 과열 민감도를 성공 결과에서 숨기지 않는다.
- 후방 지지에서 약 -50 N 반력이 요구되는 비교 조건이 있다. 양방향으로 고정한 beam 조건만으로 C형 지지의 접촉·유격·유지력·열간 정렬을 검증했다고 해석하지 않는다.
- 전체 기계의 공진·마모·피로·실물 PID·가드 내부 방사교환·재료 흐름을 이 간이 모델로 승인하지 않는다.

## 형상과 조립 상세

266개 객체의 명목 정적 검사와 운동 검사는 기존15개 참조형상 겹침을 공개한 상태다. 칼라, shim, 축의 제조 길이와 명목 유격은 검사하지만 실제 조임 토크·유지력·마찰·마모는 별도다.

뚜껑 레일/래치/인터록과 일부 센서의 정확한 모델·장착·작동 여유는 아직 완결된 실물 기반 상세가 아니다. STEP에 보이는 외형 상자를 확정된 구매품이나 실제로 체결된 브래킷으로 취급하지 않는다. 이 항목은 가공·구매·운전 전 해소할 설계/수령 HOLD다.

## 패키지의 증거 완결성 검사

제작 ZIP에는 해석 보고서의 선언된 source/dependency SHA-256을 재귀적으로 확인한다. 원격 저장소에 파일이 있다는 사실만으로 ZIP에 포함됐다고 간주하지 않는다. 누락된 중간 보고서 또는 하위 입력이 있으면 패키징을 거부한다.

상위 보고서의 해시를 다시 계산하더라도 하위 보고서의 오래된 CAD 해시가 남으면 거부한다. 검증기는 압축을 푼 내용으로 원래 상대경로를 복원해 같은 검사를 수행한다. 원본 작업 폴더에만 있는 파일로 누락을 보충하지 않는다.

이 검사는 선언된 의존 파일의 무결성이다. 제외된 대형 raw solver 디렉터리까지 모두 배포했다는 뜻이 아니며, 미선언 물리 전제의 타당성이나 실제 측정의 진실성을 증명하지 않는다.

## CI 후처리 분리

2026-09-14 CI-FULL 34848204654는 CAD 12개와 AVR 재현 및 증거 업로드가 통과한 뒤 선택적인 Magic Nix Cache 후처리에서 장시간 대기했다. 해당 실행을 최종 성공으로 바꾸지 않는다. 필수 CI에서 이 캐시 action만 제거하고 같은 고정 Nix 환경과 CAD/AVR 검사를 새 commit에서 다시 수행한다. flake.lock과 검사 기준을 바꾸지 않으며 수치 라이브러리 스레드를 로컬 검증과 같은 1개로 제한한다. 이전 실행에서 받은 산출물과 기록은 비교용으로 보존한다.
