# HS-R1-S2 냉간 실측 준비와 기록 보완

상태: `PREPARATION_ONLY`. 실물 시험은 `NOT_RUN`, 전체 기계와 가열 승인은 `HOLD`다.
이 문서는 기존 7쪽 PDF의 실측 기록 요구를 보완한다. 새 형상이나 새 재료 승인이 아니다.

## 실물 작업 전 확인

재료의 정확한 공급 상태, 열처리와 필요한 강도 근거가 있어야 한다. 17-7PH라는 이름만으로 승인하지 않는다. 도면의 가공·모서리·치수 요구, 계측기 범위와 교정, 치구 고정과 두 방향 기계식 stop을 먼저 검토한다. 구매·가공·통전은 각각의 승인 범위를 유지한다.

냉간 측정 전에는 sheet stack을 너트로 압착하지 않았는지, 실제 endplay가 0.25–0.35 mm인지 확인한다. 모든 자중과 시험 추의 위치를 포함해 carrier별 반력을 계산한다. 25 N은 이번 치구 모델 범위이며 본체의 인증된 정격이 아니다.

## 기록에 추가된 요구

- `time_s`는 음수가 아니고 엄격히 증가해야 한다. 같은 시각의 중복 표본은 승인하지 않는다.
- 편도 이동만으로는 왕복 시험을 입증하지 못한다. 두 방향의 유의한 변위가 있어야 한다.
- 위치 불확도를 포함한 실제 이동폭이 2 mm 이상이어야 한다. 기계식 ±3 mm 경계는 불확도까지 포함해 넘지 않는다.
- 온도 범위 20–300°C도 불확도 구간으로 확인한다. 경계 밖일 가능성을 버리지 않는다.
- near-envelope 횡하중은 불확도를 뺀 값이 24 N 이상이고, 불확도를 더한 값은 25 N 이하여야 한다.
- 잔류 변형에는 `residual_position_uncertainty_mm`가 필요하다. 잔류값과 불확도의 합이 0.02 mm 이하여야 한다.
- 열간 시험은 별도 승인과 보호·재료 근거를 요구한다. 기록의 인접 표본에서 구한 가열 속도가 2°C/min을 넘으면 자가신고한 ramp 값과 관계없이 거부한다. 희소 표본만으로 전체 ramp의 적격성을 보장하지 않으므로 원시 ramp trace도 필요하다.

## 결과의 의미

`MEASURED_DATA_WITHIN_TEST_PROTOCOL`은 입력 기록이 검사 조건과 일치한다는 뜻이다. parser는 실제 측정 여부나 승인·성적서의 진위를 증명하지 않는다. 모든 결과에 `hardware_authorization=NOT_GRANTED`, `measurement_authenticity=NOT_ESTABLISHED_BY_PARSER`, `machine_release=HOLD`를 남긴다.

`physical_test_template.json`은 performed=false와 빈 samples를 유지한다. 실제 원시 자료는 무시 경로 `measurements/`에 별도로 보존하며, 합성 software test를 실측 보고서로 복사하지 않는다. 실제 부품의 불합격을 기록에서 삭제하거나 불확도를 줄여 통과시키지 않는다.

CLI는 qualification/minimum_requirements.py를 통해 추가 축방향 drag 해석과 이전 요구를 결박·재계산한다. 현재 frozen 가정(mu0.25·6장 균등분담)에서 최소 입력은 1,222 MPa다. 과거1,100 MPa 문구는 추가 하중을 포함하지 않은 부분 요구다. 이 잠정 바닥값은 재료 보증이나 실제 drag의 허용 정격이 아니며, 실측 하중/온도·sheet별 분담이 달라지면 요구를 재계산해야 한다. 원본 누락·해시 변화·산술 불일치는 거부한다.


## 최신 근거와 시험 경로
qualification/SOURCE_ASSESSMENT_KO.md와 TEST_PLAN_KO.md의 M01/F01/H01/A01을 함께 읽는다. 제조사 일반표와 NACA의 다른 두께/열처리 자료는 현재 부품 성적서가 아니다. 실제 마찰 데이터는 없으며 코드/가정값을 MEASURED로 표시하지 않는다. 기존300 N은 입증된 rating이 아니고, 재료/하중 검토가 요구하는 더 낮은 중단 경계를 우선한다.
