# HS-R1-S2: 고온부 sliding 시험 기반

현재 상태는 `PRESSURELESS_PROTOTYPE_REVIEW`이며 전체 기계 release는 `HOLD`다. 가공·구매·통전·기계 장착 승인이 아니다.

## 해결 구조
좁은 원통 fit에 중심 정렬과 축방향 sliding을 동시에 맡기지 않는다. 세 탄성 슈가 반경방향 팽창을 받아들이고 중심을 지지한다. 바깥의 세 방사형 슬롯은 sheet 자체의 열팽창을 허용한다. Shoulder pin의 nut는 shoulder 끝에서 지지하고 sheet stack을 압착하지 않는다. 마찰은 0이 아니므로 실물에서 측정한다.

`fixture/`는 독립 무가압 고체 mandrel 시험치구다. 실제 압출기 지지부 교체품이 아니다. `relief_candidate/`는 기존 간섭 bore를 완화한 별도 형상이며, 독립 중심 지지 없이 단독 사용하지 않는다. 기존 rear shoulder/retainer의 축방향 하중 경로와 screw 중심 정렬도 별도 검증해야 한다.

## 실제 생성·실행한 자료
- C3D10 선정 형상 12회: 0.8/0.55/0.45 mm, 반경 preload·횡방향 두 축·균일 팽창.
- 온도 구배 6회: 반경 가열/냉각, 두께방향 구배. 두께방향 peak는 단독 수렴 완료로 보지 않는다.
- 6,144개 대수 조합: 정·역 온도차, CTE/E 가정, 부품 공차, 횡하중. 실제 FEA 6,144회라는 뜻이 아니다.
- 보어 완화 후보의 자유팽창 부품쌍48개: 간섭0. 실제 접촉/마찰/온도장 해석이 아니다.
- 합성 측정기록 검사26개. 실제 물리 시험 수는0이다.

## 중요한 수치와 제한
최소 계산 슈 법선력2.073 N, 중심 이동0.04422 mm. 여기에 실물에서 달성해야 할 설치 예산0.040 mm를 더하면0.08422 mm다. 이 설치 예산은 측정 결과가 아니다. 각 carrier의 모델 횡하중 상한은25 N이며 mandrel 자중과 모든 시험 추를 포함해야 한다.
균일 온도장 모델의 요구 항복강도는839 MPa, 구배를 포함한 검토 요구는약1,054 MPa다. 사용 온도에서1,100 MPa 이상이라는 잠정 성적서 요구를 둔다. 재질명17-7PH만으로 충족된 것으로 간주하지 않는다. 정확한 공급/열처리 상태와 온도별 강도 근거가 필요하다. 접촉, 피로, 실제 고온 마찰과 온도장은 미검증이다.

## 제작자료 사용
`HS-R1-S2_prototype_review_ko_v2.pdf`를 먼저 읽는다. `BOM.csv`는 시험치구18행이고 전체 PPR BOM이 아니다. `fixture/*.step`은 형상, `drawings/*.svg`와 PDF는 치수/검토 안내다. DXF는 STEP edge export이며 별도 CAM/profile 검토 없이 기계 가공 명령으로 사용하지 않는다. Spring 자유 형상과 mandrel이 초기에는 겹친다. 이는 탄성 preload 전의 표현이며, 실제 변형 조립체라고 오해하지 않는다.

첫 실물 단계는 재료와 치수 확인 후의 무가압 냉간 왕복 시험이다. Sheet가 힘을 받아 벌어지는지, slot이 끼지 않는지, nut가 stack을 압착하지 않는지 확인한다. 가열은 독립 차단·금속 보호판·교정 계측·사용 온도 재료 근거와 사용자 승인 후 별도 단계다. 현재 열간 적격성은 HOLD다.

## 실측 기록 보강
기존 26개 시험에 25개 경계 회귀 시험을 추가했다. 검사기는 왕복, 불확도, 시간과 가열속도를 확인하며 실제 측정 여부 또는 하드웨어 승인을 부여하지 않는다. 실물 단계 전에 COLD_TEST_READINESS_KO.md를 함께 읽는다.
