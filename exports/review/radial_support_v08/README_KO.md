# 방사방향 지지 검토용 형상

`RS-FRONT-GUIDE-CANDIDATE.step`은 앞 지지를 x125 mm로 옮겨 검토한 후보 한 부품이다. 현재 정식 GGM 조립 모델, BOM 또는 절단표를 교체하지 않는다. 정식 제조도면이 아니며 가공·구매·통전 승인도 없다.

형상과 명목 여유의 source-bound 결과는 `analysis/radial_support_v08/results/geometry.json`, 하중·축 정렬·열손실 검토는 `analysis/radial_support_v08/results/review.json`을 따른다.

다음 문서를 먼저 읽는다: `docs/reviews/radial-support-v08/REVIEW_KO.md`.

제작 승인 전 지지판/조인트의 하중, 냉간 축 위치 조정 방법, 열간 전체 공차, 히터 전력/방열, 조립·분해 절차와 정식 도면을 마감해야 한다. 후보 계산의 PASS를 완성 기계의 적합성으로 해석하지 않는다.
