# ADR-003: 외부 pre-dry, 16 mm screw, 2축 shadow gauge

- Integrated dryer는 hopper/insulation/blower/heater가 약 150 x 180 x 320 mm와 35,000–65,000 KRW를 추가하고 PET bottle flake의 sticking/crystallization 조건을 장치 내부에서 검증해야 한다.
- 외부 pre-dry + sealed 4.5 L hopper는 약 150 x 180 x 230 mm와 12,000 KRW로 줄며, 사용자가 dry completion을 확인하기 전 RUN을 막는다. 이를 채택한다.
- 16 mm x 16 L/D screw는 256 mm active length와 약 420 mm drive 포함 envelope로 cabinet width에 맞는다. 계산상 200 g/h 가능성이 있지만 commissioning 범위는 120–220 g/h이고 Gate 4 실측 전 target 달성을 주장하지 않는다.
- Raspberry Pi camera는 추가 failure domain과 조명/왜곡 보정 부담이 있으므로 제외한다. 두 직교 LED/photodiode shadow channel을 사용하고 traceable pin/wire 교정이 끝날 때까지 직경 목표 달성을 주장하지 않는다.
