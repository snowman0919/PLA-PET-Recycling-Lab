# ADR-002: VP1 체인 경로 vs 동결된 C1 구조물 릴리프 (chain routing reliefs)

- 상태: **채택 (디지털 통합 수준)**. C1 루트 소스는 동결 참조로 유지 — 릴리프는
  `c2.1/src/build_machine_integration.py`이 통합 시점에 적용하고, 결과는
  `c2.1/results/machine_integration.json`의 `vp1_stage3.chain_relief_records`에
  기록된다.
- 배경: Stage 1에서 실제 체인/기어 솔리드가 도입되면서, C1에서는 감사 대상이
  아니었던(유지 부품 간 상속 감사 제외) 접촉이 처음 측정되었다:
  CHAIN-A×S1-ROOF-R(60.4)·S1-STUD(104.7)·DRV-B12(88.8)·DRV-DECK(167.9),
  CHAIN-B×DRV-JACK(850.2)·DRV-DECK(167.7), SH40×DRV-M2(2086.9)·DRV-DECK(774.3×2).

## 옵션

1. **릴리프 포켓(채택)** — 통합 단계에서 레거시 솔리드에 절삭 포켓을 적용.
   포켓 = 접촉 영역 bbox + 마진 1.5 mm, 제거 부피를 기록.
2. **아이들러/체인 재배선** — 동결된 스프라켓 데이텀(X/Z)을 유지한 채 체인 경로를
   바꾸려면 새 스프라켓 인스턴스와 새 체인 평면이 필요해 계약(drive 레이아웃,
   매개변수) 위반. 기각.
3. **신규 부품 이동** — S1 지붕/스터드/베어링 플레이트/잭샤프트/모터 위치 변경은
   C1 동결 참조 위반. 기각 (단, JACK은 예외 처리 아래 참조).

## 결정 (부품별)

- 제거 부피(mm³)와 포켓 bbox는 `vp1_stage3.chain_relief_records` 참조.

## ADDENDUM (2026-09-22, VP1 Stage 4, rev B — SUPERSEDES the rev A decision)

rev A는 "C1 freeze가 구동 배치 자체를 동결한다"는 해석 위에 서 있었다. 이 해석은
기각되었다(사용자 결정: C1 루트 소스만 동결, 통합 빌드의 레거시 인스턴스는
이동/교체 가능). rev A의 기능 파괴적 릴리프 두 건 — DRV-JACK 절단(y 370..378.5,
후단 스텁 무토크)과 DRV-M2 8,336 mm³ 포켓 — 은 체인 B가 잭샤프트 코어를
관통하는 것과 이중 헬리컬 메시(하부 쌍 y 286..311)가 M2 참조 바디에 걸리는
것, 두 레이아웃 결함의 직접 결과였다.

### 결정 (rev B)

1. **체인 B 재배선: 구동 스프로킷을 입력축(80, 374)에서 잭샤프트로 이동.**
   새 인스턴스 `DRV-SP24-B20_002`(24T, 보어 10, 잭 y 373..381)가 체인 B를
   끈다; S2 12T(`DRV-SP12-B12_001`)는 동일 XZ 데이텀에서 y 374..382로 이동.
   체인 평면 y 376..381, 76링크(723.9 mm). 잠깐 — 잭샤프트에서 체인 B가
   접선으로 빠져나가므로 스트랜드가 잭 코어로 "되돌아오지 않는다": rev A의
   관통(코어에서 4.84 mm)은 구동 스프로킷이 입력축에 있었기 때문에 존재했다.
   토크 경로: M1 -> CPL12 -> 15T/40T -> 잭샤프트 -> {체인 A 24/24 -> S1,
   체인 B 24/12 -> S2} — 잭샤프트는 **단일 솔리드** y 240..408으로 복원
   (절단·커플링 슬리브 삭제). 토크와 베어링 반력 경로가 양단 지지로 연속.

2. **이중 메시 삭제 → 단일 15T/40T 메시.** 하부 쌍(SH15R 플립 + SH40L 플립,
   y 286..311)은 M2와 접촉하는 유일한 요소였다. 삭제하면 M2 포켓이 필요
   없어지고(모터 바디 무손상), 측정 감사에서 40L/DECK 포켓도 사라진다.
   단일 메시의 헬리컬 추력 상쇄는 (미선정, HOLD) 실제 모터/기어박스 선택에서
   해결한다. 치수 비율 15/40, 중심거 56.940 불변.

3. **삭제된 인스턴스:** `DRV-SH15R_001`, `DRV_SH40L_lower`,
   `DRV-SP24-B12_001`(보어 6 — 보어 10 드라이버로 대체). 이동 인스턴스:
   `DRV-SP24-B20_001`/`DRV-SP24-B25_001` y 354->352, `DRV-SP12-B12_001`
   y 374 유지(페이스 374..382).

4. **남는 기계가공 릴리프(정상, 기능 보존):** DECK 체인 A/B 랩 채널(각
   ~790 mm³), DECK 40T 팁 원(5,051 mm³), B12 코너(442 mm³, 베어링 시트
   보존), ROOF-R 코너(478 mm³), STUD 테일 트림(y>330.5, 벽간 스팬 보존).
   rev A의 기능 파괴 릴리프(잭 절단, M2 거터)는 존재하지 않는다.

5. **감사 증거(스테이지 4 실행):** 잔여 접촉은 FUNCTIONAL_PAIRS(체인 랩
   물림 4, 키 시트 5)뿐. 문서화된 C1 내부 접촉(이 빌드가 감사하지 않는
   보존-내부 쌍): S1-SYNC_001/002 × S1-BR-CAP_001 685.7 mm³ 각.
   예비 감사(/tmp/layout10.py, 레이아웃 v8): 릴리프 후 unexpected = 0.

### REV B 부록 2 (2026-09-22, Isaac 통합 피드백 2건)

1. **S2 회전 방향(체인 B 잭 구동 → S2Ecc = -0.75 x 입력).** 외부 메시(15/40)가

   수로 전 구간 연속 중력 활주 주장은 하지 않는다(채널 중간의 재킷 상면

   방향 net-down + 단계 에지 수직 하류면 = 파편 단조 전진"이다. 체크포인트

## ADDENDUM 3 (2026-09-23, VP1 Stage 5 활성 오거 — 연결 이송 HOLD)

### 배경과 폐기된 시도

수동 계단/웨지 리브, 패들+스크레이퍼, 얕은 r4/r5 오거는 기하 게이트를
통과했어도 Isaac 시뮬레이션에서 지속 이송하지 못했다. 이 결과는 최종
성공 증거가 아니라 부정 시험 이력으로만 유지한다. 현재 설계는 이전
`x246..261` 수동 적체 구역까지 포함해 x237..354 슈트의 일부를 능동화한다.
S1 팬 전체와 S2 입구의 횡방향 연결은 국부·연결 소재 시험에서 여전히 확인해야 한다.

### 최종 측정 형상

1. **트로프**: x237..354, y213..251의 구조 바닥과 y223.3..240.9
   개방 U-쉘. 측정한 S2 재킷 돔 상면 z334.5를 피하고, x354..360에서
   z330으로 하강한다. BRep 플라이트/U-쉘 최소 간극은 0.032 mm다.
2. **AUG_SHAFT**: 축 +X, `(y232, z347.1)`, 샤프트 r3 x236..370.
   RH 플라이트 root r3 / OD r8, 피치 28.5 mm, 3 mm 축방향 웹,
   네 턴 x238.5..352.5(스윕 외곽 x237.343..354.681).
   전장 모형의 서단 베어링은 x233..239로 S1 팬의 낙하 입구와
   겹친다. x83..237 팬 전체가 능동 플라이트 안에 있다는 뜻이 아니다.
3. **구동**: S2Ecc 12T → PDL_CHAIN 35링크(오프셋 링크) →
   `(x362, z374.5)`의 PDL_SPROCKET/PDL_SHAFT → RH 2-start
   PDL_WORM → 16T AUG_WHEEL. 34링크 명목 길이 323.85 mm는
   중심거리 기준 경로 332.734 mm보다 8.884 mm 짧아 조립 불가였고,
   35링크 333.375 mm는 0.641 mm 남는다. 오프셋 링크 강도와 장력은
   미정격 HOLD다.
   감속비 8:1. 참조 M1 58 rpm에서 15T/40T 기어쌍과 체인 B
   24T/12T를 거친 S2 편심축은 -43.5 rpm이고 오거는 -5.4375 rpm이다.
   RH 플라이트는 음의 회전에서 +x로 이송한다. 이전 -10.875 rpm은
   잭샤프트 전단의 15/40 감속을 빠뜨린 값이므로 폐기한다.
4. **삭제**: 패들, 스크레이퍼, 정적 웨지 리브, 단계형 채널은
   설치하지 않는다. S1 팬의 미구동 구간은 폐기됐다고 주장하지 않는다.

### 검증 경계와 HOLD

- STEP 기하, BRep 간극, 조립 무충돌은 디지털 형상 범위의 증거다.
  과거 국부 17/22 x335 도달은 60초에 M1 130×8회전(1040 rpm)으로
  가속한 비현실적 실행이고, 9/22가 world 유실되었으므로 이송
  합격으로 사용할 수 없다. 16초 연결 실행에서는 오거가 0.75회전해
  피치 기준 최대 21.375 mm만 전진하므로 0/200 B4는 이 시간 구간의
  미도달이다. S1 팬 서측 공급과 S2 입구 횡방향 인계는 별도 결함이다.
- 웜/휠, 축, 베어링, 모터는 **REFERENCE/UNRATED**다. 토크, 효율,
  열, 마모, 수명, 파편 물성 변화와 실제 처리량은 물리 시험 전 미검증이다.
- 본 결정은 구매·제작·통전 승인이 아니다. 해당 단계는 release HOLD를
  유지한다.
