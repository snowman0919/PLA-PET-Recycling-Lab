# ADR-002: VP1 체인 경로 vs 동결된 C1 구조물 릴리프 (chain routing reliefs)

- 상태: **채택 (디지털 통합 수준)**. C1 루트 소스는 동결 참조로 유지 — 릴리프는
  `c2.1/src/build_machine_integration.py`이 통합 시점에 적용하고, 결과는
  `c2.1/results/machine_integration.json`의 `vp1_stage3.chain_relief_records`에
  기록된다.
- 배경: Stage 1에서 실제 체인/기어 솔리드가 도입되면서, C1에서는 감사 대상이
  아니었던(유지 부품 간 상속 감사 제외) 접촉이 처음 측정되었다:
  CHAIN-A×S1-ROOF-R(60.4)·S1-STUD(104.7)·DRV-B12(88.8)·DRV-DECK(167.9),
  CHAIN-B×DRV-JACK(850.2)·DRV-DECK(167.7), SH40×DRV-M2(2086.9)·DRV-DECK(774.3×2).

## 옵션

1. **릴리프 포켓(채택)** — 통합 단계에서 레거시 솔리드에 절삭 포켓을 적용.
   포켓 = 접촉 영역 bbox + 마진 1.5 mm, 제거 부피를 기록.
2. **아이들러/체인 재배선** — 동결된 스프라켓 데이텀(X/Z)을 유지한 채 체인 경로를
   바꾸려면 새 스프라켓 인스턴스와 새 체인 평면이 필요해 계약(drive 레이아웃,
   매개변수) 위반. 기각.
3. **신규 부품 이동** — S1 지붕/스터드/베어링 플레이트/잭샤프트/모터 위치 변경은
   C1 동결 참조 위반. 기각 (단, JACK은 예외 처리 아래 참조).

## 결정 (부품별)

| 부품 | 처리 | 근거 |
|---|---|---|
| S1-ROOF-R_001 | 포켓 (체인 랩 채널, 코너 절삭) | 브래킷 코너 제거, 하중 기능 유지 |
| S1-STUD_001 | 트림 (y>350.5 테일 제거) | 벽 간 인장 스팬 y 108..329.6 보존 — 체인이 지나는 y 351.5..359 구간만 절제 |
| DRV-B12_001 | 포켓 (상동 코너) | 베어링 시트(x 74..86) 미접촉 |
| DRV-DECK_001 | 포켓 ×4 (체인 A/B, 40T 기어 원) | 플레이트 절삭 구멍 — 구조 기능 유지 |
| DRV-M2_001 | 포켓 (참조 바디) | M2는 미소유 참조 — 실 모터 장착이 지켜야 할 8 mm 기어 클리어런스 표시 |
| DRV-JACK_001 | **절단 (y 370..378.5), 무커플링** | 체인 B 스트랜드가 샤프트 코어를 관통(축중심에서 4.84 mm 오프셋, 체인 밴드 ±5.5) — 샤프트를 체인 밴드 구간에서 절단. 후단 스텁(y 378.5..408)은 스프라켓·기어 물림 구간 뒤쪽이라 토크를 전달하지 않으며 DRV-B20 베어링에 스페이서로 유지됨. 커플링 슬리브(r ≥ 10.2)는 체인(반경 ≤ 9.7)과는 0.5 mm 이상 이격되지만 SP24-B20 허브(r 20, y 362..372)를 피할 수 없어 기각 |

기각 근거: JACK의 턴다운(직경 축소)은 체인이 축심을 관통하므로 불가(잔여 r ≤0.7);
스터드 절단은 벽 간 스팬 상실. 두 경우 모두 구조적 기능 상실 → 위 표의 방식 채택.

## 증거

- 적용 후 감사: vp1_against_retained/vp1_internal unexpected = 0.
- 남는 접촉은 FUNCTIONAL_PAIRS(저널 끼워맞춤, 기어 물림, 키 조립, 사이클로이드
  링 물림)뿐.
- 제거 부피(mm³)와 포켓 bbox는 `vp1_stage3.chain_relief_records` 참조.
