# GGM 프레임 R1: 절단표와 실제 재고를 연결하는 절차

현재 설계 식별자는 `GGM_FRAME_R1_REDUCED_20260912`다. 최종 GGM CAD에 대응하는 명목 절단표는 `exports/fabrication/frame_cut_list.csv`, 사람이 읽는 도면은 `exports/final/frame_v08/FRAME_CUT_AND_TIE_KO.pdf`다. 원래 공개 v1.0.0-rc1 ZIP에는 이번 수정이 들어 있지 않다.

## 변경 범위

2020은 38개/15,567 mm에서 36개/15,078 mm로 2개/489 mm 줄였다. 2040은 4개/2,180 mm 그대로다. 총 프로파일은 42개/17,747 mm에서 40개/17,258 mm로 변경됐다. 분쇄기·모터·추력·고온부·피더 지지는 유지한다.

바닥 `FrameBottomCross275` L430은 그냥 빼지 않고 FR-TIE-01 S275JR 강판 연결재로 대체한다. `SpoolTopSegment290` L59는 한쪽 끝만 연결된 남은 조각으로 제거한다. 프로파일 재고를 절약하는 변경이며 무게·총비용 절감은 주장하지 않는다.

FR-TIE-01은 완성 U40x20x3, 내부 R3, 길이470 mm다. 위치 X0/Y265/Z20, 구멍 X10/460 및 로컬 Y12/28에 Ø5.5 네 개다. 와셔 외경10 mm 이하가 굽힘부를 피하도록 간격을 잡았다. M5x10 class8.8+와셔+수령 프로파일에 맞는 T-nut 네 조를 사용하되, 실제 물림·바닥 닿음·제조사 토크 확인 전 조립 승인값으로 간주하지 않는다. 평판 전개 길이는 실제 금형 굽힘 여유를 확인한 후 확정한다.

## S0 / P1

가공·통전하지 않고 bar별 식별자, 단면, 실제 사용 가능 길이, U95, 상태와 원시 사진을 기록한다. P1 structured detail의 `profile_type`은 2020/2040이고 `frame_cut_list_sha256`은 현재 절단표의 SHA-256이어야 한다. 구형 기본 배치 표나 다른 프레임 revision에 결박된 기록을 재사용하지 않는다.

P1의 합계 길이 검사는 실제 절단 배치의 성립을 뜻하지 않는다. 짧은 여러 bar는 합계가 충분해도 L890 기둥을 만들 수 없다. 명목 길이보다 긴 여유가 있어도 실제 bar별 배치가 없으면 절단하지 않는다.

## P2

`frame_release.py`가 현재 파라미터·GGM native/STEP·형상 검증·비교계산·절단표의 해시와 40개 부재의 1:1 대응을 먼저 검사한다. 하나라도 변하면 이전 frame release는 무효다. `profile_nesting.py`는 bar 길이-U95에서 부재별 명목 길이+0.5 mm 절단 허용차 상한과 승인된 kerf를 차감한다. 끝단 손상·정리 여유는 입력의 usable length에서 먼저 제외한다.

원래 부재의 재절단/재사용은 실제 bar ID를 새 절단 배치에 한 번만 배정한다. 기존 조립체에 남겨 놓을 bar를 동시에 재고로 사용하지 않는다. `frame_connections.csv`는 CAD 접촉 대상 목록일 뿐 체결품 개수나 슬립 강도 인증이 아니다. 조립 전 각 연결의 실제 bracket/T-nut, 나사 물림, 간섭과 공구 접근을 대조한다. SYS-01의 56 kits는 과거 기본 프레임 계획 수량이며 최종 GGM 전체 체결품 수량으로 사용하지 않는다. FR-TIE 네 조는 별도다.

실제 절단은 현재 P1/GGM receipt/bar 기록/절단표/kerf와 결박된 P2 사용자 승인 후에만 진행한다. 냉간 squareness·대각선 차이·흔들림·축 정렬 기준은 낮추지 않는다. 실패하면 같은 최종 기계의 원시 증거를 보존하고 설계 변경 후 재시험한다.

## 검증 범위

CAD 새 간섭 없음, retained shape 불변, formed tie의 와셔·구멍 여유를 디지털 검사했다. 3D 선형 beam의 18개 민감도 설정, 각27개 단위 하중을 비교했으며 이는 실제 joint/slip·강도·피로·진동·실물 안전 인증이 아니다. 부품 실측/물리시험은 NOT_RUN이고 실제 재고 충족 여부는 아직 미확정이다.
