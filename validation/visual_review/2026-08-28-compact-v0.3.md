검토일: 2026-08-28. 검토자는 source shape에서 software-render된 1600 x 1200 PNG 원본과 PDF page raster를 직접 확인했다.

## Before 기준

Immutable archive commit `5d83e165466c6a8a1f4c159d198baaa1c2768e59`의 assembly/PDF는 이전 연구 snapshot이다. Archive render는 장거리 배치, 다단 input 처리와 대형 control 구조를 설명하므로 compact 제작 기준으로 사용하지 않는다. 상세 ref는 `docs/archive_index.md`에만 둔다.

첫 compact render review에서 다음 결함을 발견했다.

- CAD volume 출력 질량 2,064.2 g: 2.0 kg review threshold 초과.
- PSU와 extruder keep-out 10 mm 중첩, cable duct와 PSU 관통.
- 두 cutter shaft의 disc가 같은 axial plane에 있어 nominal collision.
- Bearing plate가 solid라 shaft/bearing seat가 실제로 통과하지 않음.
- Section이 triangle hide 방식이라 절단면/내부 path 증거가 약함.
- Tool-access annotation이 bolt가 아니라 motor를 가리킴.

## 판정

- 전체 외형: PASS (CAD nominal).
- 부품 관통/cutter collision: PASS (선정 critical pair, nominal).
- Hopper reach, fragment containment, 실제 bolt wrench swing: PHYSICAL GATE.
- Screen 제거: 좌측 slide path와 handle이 보이나 실제 guard/fastener coupon 필요.
- Screw 인출: cassette 전체를 front로 제거한 뒤 cabinet 밖에서 수행; 외부 service clearance 필요.
- Hot-zone/polymer: metal shield 뒤 배치 PASS (nominal), seam/slot 열전대 필요.
- Cable/moving part: fixed rear duct와 spool keep-out nominal PASS; 실제 bend radius는 donor cable 확인 필요.
- Center of gravity/tip: heavy PSU/hot zone이 하부에 있으나 실제 mass/anchor pull test 필요.
- Print 210 mm: PASS. Support 제거성은 slicer/first article 필요.

결론: automated design-package gate용 visual review는 완료했다. Fabrication/operation acceptance는 물리 Gate 1–5 전 보류다.
