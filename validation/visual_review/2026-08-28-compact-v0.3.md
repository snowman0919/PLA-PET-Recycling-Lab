## Before 기준

Immutable archive commit `5d83e165466c6a8a1f4c159d198baaa1c2768e59`의 assembly/PDF는 이전 연구 snapshot이다. Archive render는 장거리 배치, 다단 input 처리와 대형 control 구조를 설명하므로 compact 제작 기준으로 사용하지 않는다. 상세 ref는 `docs/archive_index.md`에만 둔다.

첫 compact render review에서 다음 결함을 발견했다.

- CAD volume 출력 질량 2,064.2 g: 2.0 kg review threshold 초과.
- PSU와 extruder keep-out 10 mm 중첩, cable duct와 PSU 관통.
- 두 cutter shaft의 disc가 같은 axial plane에 있어 nominal collision.
- Bearing plate가 solid라 shaft/bearing seat가 실제로 통과하지 않음.
- Section이 triangle hide 방식이라 절단면/내부 path 증거가 약함.
- Tool-access annotation이 bolt가 아니라 motor를 가리킴.
- Follow-up review에서 CUT-01이 4-point saw/petal silhouette로 보여 cycloidal-inspired hook 근거가 불충분함.
- 첫 blind-keyway 구현은 boolean 길이가 과도해 tooth 외곽까지 열릴 수 있었고, 6004 outer ring의 축방향 retainer가 assembly/BOM에 없었음.
- Tool-access render의 화살표가 실제 M6 through-bolt가 아닌 빈 공간을 가리켰음.
- Shredder motor가 exact model 없이 generic red keep-out이었고 120 W power assumption이 실제 actuator 선정과 불일치함.
- 첫 motor 수정안의 custom M2 Z24 phase gear는 표준 gear surface torque 4.24 N·m 수준이라 14–24 N·m 경로에 부적합함.

수정 후 출력 질량은 1,100.5 g다. FreeCAD nominal check는 PSU/hot zone, cable/PSU, spool/dancer/forming/control critical pair, 36 cutter pair, 2.0 mm screen gap과 shaft/bearing ring을 통과했다.

Follow-up에서 CUT-01을 cycloid displacement 식으로 재작성하고 고밀도 fabrication STEP/DXF와 저밀도 assembly LOD를 분리했다. Keyway는 root 안에서 끝나는 6.2 x 6.0 mm blind cut로 수정하고 root material probe를 자동검증에 추가했다. CUT-03과 같은 좌표를 쓰는 CUT-08 steel bearing retainer를 추가하고 tool-access 화살표를 실제 through-bolt로 이동했다. Motor는 `MY1016Z-24V-250W-75RPM`, current sensor는 ACS758 50 A, coupling은 KTR ROTEX19 98ShA bore17/20, phase gear는 KHK SS3-16H M3 Z16으로 특정했다. 250 W motor 때문에 all-peak 합이 862 W임을 드러내고 shredder와 heater/screw 상호배제를 추가했다.

## 판정

- 전체 외형: PASS (CAD nominal).
- 부품 관통/cutter collision: PASS (선정 critical pair, nominal).
- Hopper reach, fragment containment, 실제 bolt wrench swing: PHYSICAL GATE.
- Screen 제거: 좌측 slide path와 handle이 보이나 실제 guard/fastener coupon 필요.
- Screw 인출: cassette 전체를 front로 제거한 뒤 cabinet 밖에서 수행; 외부 service clearance 필요.
- Hot-zone/polymer: metal shield 뒤 배치 PASS (nominal), seam/slot 열전대 필요.
- Cable/moving part: fixed rear duct와 spool keep-out nominal PASS; 실제 bend radius는 donor cable 확인 필요.
- Center of gravity/tip: heavy PSU/hot zone이 하부에 있으나 실제 mass/anchor pull test 필요.
- Print 210 mm: PASS. Support 제거성은 slicer/first article 필요.

결론: cutter/motor follow-up visual review는 완료했다. 다만 exact parts를 신규 구매하는 cash rollup 309,900 KRW가 hard cap을 초과하므로 automated release와 main 승격은 FAIL/보류다. Fabrication/operation acceptance도 물리 Gate 1–5 전 보류다.
